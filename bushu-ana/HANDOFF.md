# bushu-ana（部首穴・ぶしゅあな）— 引き継ぎメモ

子ども用（学習系ゲーム）。穴にお菓子を落とすゲーム（Hole.io系）のオマージュ。
**あなを うごかして、ステージの 部首の 漢字だけを のみこむ。のみこむほど あなが 大きく なる。ちがう部首を のみこんだら いっぱつ アウト。**

  ステージごとに さんずい・うかんむり などが 決まり、それに くっつく 漢字を 穴に 入れていく。

  さんずい じゃない 字を 入れたら いきなり ゲームオーバー。とりあえず ステージを 1つ。名前は「部首穴」」

## しくみ（index.html 1ファイル＋ three.min.js r128 同梱）
- 3D は three.js（kanji-bouken と 同じ r128 を コピー）。**漢字ブロックは しゅるいごとに InstancedMesh**（うえ と まえの 面に 漢字の テクスチャ）。
  1044こ でも draw call 約240・60fps（Mac で 確認）。`frustumCulled=false` は 必須（InstancedMesh は 原点で カリングされて 消える）。
- **あな**: じめんは 自前シェーダ。あなの 円の 中を `discard` して くりぬき、下に 内がわだけ 見える 円柱（かべ）と 黒い そこ。
  ふちの 輪が 青く のびるのが「つぎの レベルまでの すすみ」。かげ（InstancedMesh）も あなの 上では discard。
- **のみこむ はんてい**（`checkSwallow`）: `s×FIT(0.62) ≤ 半径` なら 入る大きさ。中心が `半径 − s×0.22` より 内がわで 落ちはじめる。
  大きすぎる ものは あなの 上で ぐらぐら（`updateWobble`）＋「大きく なったら のみこめるよ」ヒント 1回。
  落ちる ブロックは あなに ついてきながら かたむいて 落ちる（`updateFalling`）。0.14びょうで「のみこんだ」に かぞえる。
- **にせもの**（ちがう部首）が 落ちはじめた しゅんかん `gameOver()`: 赤フラッシュ＋スロー＋カメラが その字へ よる → アウト画面で
  「『梅』は きへん（木）の かんじ。にている『海』は さんずいの なかま！」と 部首と よみを 見せる。
- **レベルアップで あなが 大きく なった とき 下に きた にせものは ふちの 外へ おしだす**（`pushDecoys`）。うごかしていないのに アウト、を ふせぐ。
- そうさ: どこを さわっても ドラッグした むきへ すすむ（ゆびが 90px 以上 はなれたら 起点が ついてくる）。PC は 矢印／WASD・Esc で ひとやすみ。
- カメラ: 見おろし 58°。あなが 大きく なると ひいていく。たて画面は さらに ひく。
- HUD: タイム／あなLv／のこり かず＋バー／🔊／⏸、はじめて のみこんだ 字の よみ（NEW）、れんぞく（8から 4ごと）、ミニマップ（**にせものは 出さない**＝よむのが 大事）、
  のこり 25こ 以下で 画面の はしに いちばん 近い 3この 矢じるし。
- 効果音は WebAudio 合成。ポコッは れんぞくで 音程が 上がる。BGM は かがせん先生の 漢字の歌（1〜3年）を ランダム（その12）。

## ステージの つくり（`STAGES` に 1つ 足せば ふえる）
- `kanji`: [字, よみ]（なかま）／`decoys`: [字, 部首名, よみ, にている なかまの字]。にている字が ある ときは その字の 列に まぜる（海の 列に 梅）。
- 配置は **seed つき 乱数で 毎回 同じ**（「ステージ」として おぼえられる）。マップ 72×96 を 12×12 の ブロック 48こに わけ、
  中心から 近い じゅんに 小(14)→中(14)→大(13)→でっかい(7)。形は grid／pyramid（つみあげ）／rows（2字の しま）／rings／scatter。
  大きい 段から おいて、入りきらない ぶんは 下の 段へ まわす → **なかまは かならず target（1000）ぴったり**。字は ふくろ方式で 全しゅるい 出る。
- にせもの 44こ（実際は 41〜44こ）。**にせもの どうしは 9 以上 はなす**: 2この にせものに はさまれた なかまは 大きい あなでは とれなく なり
  クリア不能に なった（自動プレイで 発見）。上下に つんだ 場所・スタート付近（7いない）には おかない。
- 大きさの 段 `TIERS`（よこ 0.9/1.7/3.0/5.0・点 1/3/8/20）、レベル表 `LEVELS`（14段・半径 0.75→5.2）、★の タイム（7分/11分）は **ぜんぶ 叩き台**。

## その2（2026-10-13）: ちびっこブロック・にせものの ふやしかた・漢字クイズで 1UP
ユーザー:「全部の場所に ダミーが あるけど、ない ところが あっても いい」「もう1つ 小さいものも。小さいものは ダミーなし」
「レベルが 上がれば ダミーが 増えるのは アリ」「クリア後に 今回出てきた 漢字を 5つ 当てたら 1UP（1ど ゲームオーバーに なっても その場で やり直せる）」
- **ちびっこ段**（`TIERS[0]`・よこ0.5・1点）を 追加。スタート地点の まわり 4ブロック（220こ）に ならべる。**にせものは 入れない**。
  これで 段は 5つ（ちびっこ／小／中／大／でっかい・点 1/2/4/10/25）。`LEVELS` も 点に あわせて 見なおした（3100点で 最大）。
- **にせものは 大きい 段ほど 多い**（`DECOY_BY_TIER` = [0, 9, 15, 16, 0]）＝ レベルが 上がってから 行く ところほど ふえる。
  わりあいで いうと 小 約2%／中 約5%／大 約12%。でっかい段には おかない。
- **にせものが いない ブロック**: ブロックの 30%（`DECOY_FREE`）は にせものを おかない。にせものは 合計 だいたい 24〜32こ（前は 44）。
- **かんじクイズ**（クリア画面の「✏️ クイズに ちょうせん」）: こんかい のみこんだ 字から 5もん。「□ぐ（およぐ）」の □に はいる 字を 4つから えらぶ。
  えらぶ字には **にている にせもの**（泳… なら なし、深 なら 探）も まぜる。まちがえると「『探』は てへん（扌）。さんずいじゃ ないよ」。
  クイズの ことばは `kanji` の 3・4番め（`['泳','およぐ・エイ','□ぐ','およぐ']`）。字を 足すときは ここも 書く。
  **5もん ぜんぶ せいかいで 1UP**。クリア 1回に つき 1回だけ（やりなおしで 1UPを ふやせない）。
- **1UP**（セーブの `oneUp`・さいだい 9こ・`ONEUP_MAX`）: アウトの 画面に「❤️ 1UPで ここから つづける」。
  のみこんだ にせものは きえる・まわりの にせものは ふちの 外へ おしだす・**2びょう むてき**（`G.safeT`）。HUD と タイトルに もっている かず。
  アウトの スロー中に おちた なかまも かぞえる（1UPで つづけた ときに 1000こに とどかなく ならないように）。
- 検証: 自動プレイで seed 6とおり すべて 1000こ クリア。クリア→クイズ 5もん せいかい→1UP 1こ→つぎの プレイで アウト→1UPで つづける→
  1UPが 0に なり、つぎの アウトでは つづけるボタンが 出ない、まで 確認。

## その3（2026-10-13）: アレンジ — 分かれる演出・フィーバー・きんの かんじ・ひとこと・ミッション・大きい字の 演出・きせかえ
ユーザー:「もう少し 勉強に なる 感じや エフェクトを」→ こちらから 9案 提案 → ①⑥・②④・③⑦⑧ を えらんで もらって 実装。
- **① 部首と つくりに 分かれる**（`piecesOf()`／`FX.split()`）: おちる ブロックから 氵が あなへ すいこまれ、つくりが ポンと はねる（3D スプライト）。
  字ごとに「インクが いちばん すくない たての 線」で きる（氵の 点が つくりに くっついて かかれる 字が 多く、形で わけると くずれた）。データ不要＝どの字でも。
  左の フィードは「氵＋（つくりの 絵）＝泣 なく・キュウ」（`eqHTML()`）。大きい字では 画面中央に 大きく 出る。ちびっこ段は 出さない・小さい字は 0.18びょうに 1回まで。
- **④ ひとこと**: `kanji` の 5番め（例 泳＝「水の 中を すすむ」）。ずかんに はじめて のる 字の フィードと、ずかんの マスに 出る。字を 足すときは ここも 書く。
- **⑥ フィーバー**: れんぞく 30（`FEVER_COMBO`）ごとに 8びょう（`FEVER_SEC`）。ふちが 虹色・まわりも 虹に 光る・**なかまだけ** すいよせる（半径＋2わり）・BGMが はやく なる。にせものの はんていは かわらない。
- **② きんの かんじ**（`GOLD_N`=12・小／中の 段・13いじょう はなす）: のみこむと はやおし 2たく（`GQ_SEC`=8びょう）。えらぶ字は にている にせもの（湯 なら 場）。
  せいかいで ごほうび ランダム: 🧲じしゃく 10びょう（`magnetPull`）／⚡スピード×1.5 10びょう／🌈フィーバー。まちがい・時間ぎれは 何も へらない。
  きんの 字は 金の テクスチャ＋上で ✨（`SPARK`）。KINDS に「金の 版」を べつに 足している（`gold:true`。ずかんの かぞえは 字で まとまる）。
- **③ ミッション**: プレイ 8びょうめから 1つずつ（上の まん中）。「『海』を 20こ」「よみが『な』で はじまる かんじを 6こ」「15/25れんぞく」「（いま のみこめる いちばん 大きい）かんじを 3こ」。
  たっせいで つぎの レベルまでの 3わりの 点＋ `S.missions`＋1。つぎは 4びょう後。
- **⑦ 大きい字の 演出**（大・でっかい段, `bigEatFX`）: 0.35びょう スロー・画面ゆれ・しょうげきはの 輪（じめんシェーダの `uWave`）・光の つぶ（`FX.burst`・Points 600こ を つかいまわし）・ドーン音。レベルアップでも 輪＋つぶ。
- **⑧ あなの きせかえ**（タイトルの 🎨）: あお／ほのお（ミッション3）／ほし（ミッション10）／みずしぶき（クリア）／にじ（★3）。じめんシェーダの `uSkin` で ふちを かく。
  ガチャなし（きまった 目標で ひらく）。セーブ `missions`・`golds`・`skin` を 追加。
- 検証: 自動プレイ 5とおり すべて 1000こ クリア（きんの 字・フィーバー・ミッションが 入った 状態で）。きんの 字→せいかい→じしゃく、ミッション表示、フィーバー表示、
  ほのおの ふち、きせかえ画面を 画面で 確認。Mac で 60fps・draw call 約300。
- **未確認**: 実機 iPad の fps（エフェクトが ふえた）。重ければ `FX` の つぶの かず・`SPL` の かず を へらす。

## その5（2026-10-13）: あなの 中で とまって 落ちない バグ／まん中の 大きい 式を けす
ユーザー:「たまに あなに 入らない ものが ある（スクショ: あなの まん中に 湖が のったまま）」「まん中の 大きい字の 演出が じゃま」
- **原因**: あたり判定の 近道 `GRID` が「さいしょに おいた 場所」で 引いていた。🧲じしゃくで とおくから ひきよせた 字は
  元の 場所が しらべる はんいの 外 → あなの 中に いても 判定されなかった。→ **GRID を いまの 場所で 引く**（うごかしたら `regrid()`、`resetRun` で `rebuildGrid()`）。
- 自動プレイで さらに 見つけた: じしゃくが なかまを **にせものの 真上へ** ひきよせて（0.09 まで）その字だけ とれなく なり クリア不能。
  → じしゃくは にせものの となり（ふたりの はば＋0.9 いない）へは ひきよせない（`DECOYS`）。
- 同じ 理由で「レベルアップ時に にせものを ふちの 外へ おしだす」を やめた（おしだした 先に なかまが いると くっつく）。
  かわりに その にせものは **うかせて ぐらぐら（`o.immune`）**。あなが はなれる（中心が 半径＋はば/2 より 外）まで 落ちない。1UPで つづける ときも 同じ。
  immune は `updateWobble` で 毎フレーム 見はるので、あなが 一気に とおくへ いっても ちゃんと もどる（テスト ずみ）。
- **まん中の 大きい 式（eqBig）は 削除**。分かれる 演出（3D の 氵と つくり）と 左の フィードの 式は のこした。中サイズ以上の スロー・ゆれ・ドーン音・しょうげきは も のこした。
- 検証: 6とおり × じしゃく ずっと ON／OFF の 12回 すべて 1000こ クリア・「あなの 中に のこった 字」0。
- メモ: ユーザーは file:// で Safari から ひらいている。file:// では sw.js が 動かないかわりに Safari が 古い ページを もつことが ある → ⌘R（だめなら ⌥⌘E で キャッシュを からに）。

## その6（2026-10-13）: 大きい字の スローも 削除
ユーザー:「大きい ブロックを 入れた ときの スローも なくして」「ドンの 音・画面ゆれ・しょうげきはの 輪も」
→ **大きい字の 演出（bigEatFX）は まるごと 削除**（スロー・ゆれ・輪・光の つぶ・ドーン音）。大きい字も ふつうに 落ちて、氵と つくりに 分かれる だけ。
  大きい字の のみこみ音も ふつうの ポコッに（ひくい ボフッは ドンに きこえた）。

## その7（2026-10-13）: 500こに・漢字が 意味どおりに うごく（型）
ユーザー:「元の ゲームに にすぎている → ちがう 要素を」→ 5案（A 意味で うごく／B つくりを あつめて 漢字を つくる／C 部首スイッチ／D ステージの しかけ／E 熟語コンボ）を 提案。
「A が おもしろいが、うかんむり 等で 意味どおりは むずかしくない？」→ **型 方式**で 合意: 動きの 型を 10こくらい 作り、合う 字にだけ つける（全部は うごかさない・3〜4割で 十分）。
- `MOVES`（型）と `updateMovers()`。字への つけかたは `kanji` の **6番め**。さんずいで つけたのは 7字:
  泳 にげる（のみこめる 大きさの ときだけ・あなより おそい）／流 ながれる（右へ・はしで 左から）／消 きえる（4びょうに 1.4びょう）／
  深 しずむ（5びょうに 1回）／波 ゆれる／洗 まわる／満 ふくらむ（見た目だけ。あたり判定の 大きさは かわらない）。
  きえて いる・しずんで いる あいだは のみこめない（`o.hidden`）。きんの 字は うごかない。つんだ ものは 位相が おなじ（`ph` は 場所から）。
  うごく 字は にせものの となりへは いかない（`nearDecoy`）。はじめて 近くで 見た 型は「🐟『泳』（およぐ）は およいで にげる！」と ヒント。イントロにも 一言。
- **うかんむり など 次の 部首**: 表で 合う 字にだけ 型を つける。案: 守=まもる、家・室・宿=かくす（中に 別の 字）、寒=ふるえる（ゆれる）、実=ふくらむ、宝=ひかる、客=あるく。
  型を ふやすときは `MOVES` に 1行＋ `updateMovers` に case 1つ。動きの 字が 多い しんにょう・てへん・にんべんが いちばん 向いている。
- **500こ**: `target: 500`。マップ 72×96 → **72×72（6×6ブロック）**、ちびっこ110・中125・大40・でっかい12・のこりが 小。にせもの `DECOY_BY_TIER`=[0,6,9,9,0]（実際は 15〜20こ）、
  きんの 字 8こ、`LEVELS` は 点が へった ぶん だいたい 半分に、★は 4分／7分（叩き台）。
