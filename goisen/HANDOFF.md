# goisen（語彙線・ゴイセン）— 引き継ぎメモ

子ども用（学習・記録系）。もじ盤を **てきとうに なぞって 線を ひくと、線の とちゅうに かくれた ことば** で モンスターに こうげきする。
ねらいは「何も知らずに 適当に やっていたら ことばが できて、1年生も 6年生・中学の ことばに 出会う」こと。

## 経緯（2026-10-06）
1. 最初は `kotoba-puzzle` として 作った「なぞり版」。ユーザー評価は「言葉が難しくて作れない・玉が動く感じがない」→ いったん ボツにし、
   kotoba-puzzle は パズドラ式の「部首パズル」に 作りかえた（そちらは そのまま 別アプリとして 保留中）。
2. その後ユーザーから「**たくさん適当に線を繋ぐ という意味では面白かった**」と 再評価。語彙を ふやして 別アプリ「語彙線（ゴイセン）」に した。
   - ユーザーの指定: **3もじ以上の ことば → 必殺技／1本の 線で 2つ以上 → 別の 必殺技**
   - なぞり版の コードは kotoba-puzzle の 初版（未コミット）を もとに している。

## 四字熟語チャンス（2026-10-06 その2・ユーザー依頼）
「必殺技も 勉強に ちなんだ ものに。四字熟語の 問題（6びょう）に こたえれば めっちゃ強い技、しっぱいなら 通常技。よみがなも。敵も 強く」
- 3もじ以上 か 1本で2つ以上 → **必殺技チャンス** → 四字熟語の 問題（`yojiQuiz()`）。**時間せいげんは なし**（`YOJI_MS`=0。はじめ 6000＝6びょう だったが「子どもには 短すぎる」で なくした。もどすなら 6000）。
  - 型は 2つを 半々: 「□に はいる 漢字」4たく／「いみ → 四字熟語」3たく。熟語には かならず ルビ（`yojiRuby()`）。
  - 正解: その 四字熟語が 技名の カットイン（`yojiCutIn()`）、ばいりつ = **ながことば・れんけつの 大きいほう × YOJI_BONUS(2)**、
    りょうほう 出たら さらに ×1.25、❤ +10（`YOJI_HEAL`）。
    ※最初は かけざん（最大18ばい）に していたが、敵が 一瞬で たおれたので「大きいほう」に した。
  - ふせいかい・時間ぎれ: **通常技**（ばいりつ 1）。正しい 答え＋よみ＋いみを 2びょう 見せる。armor は 正解の れんけつで ないと やぶれない。
- `YOJI` = [熟語, よみ, いみ] 65語（index.html の 中。**1行 足せば 問題が ふえる**）。いみは 子どもむけの たたき台。
- ずかんの 先頭タブ「四字熟語」: 正解した 熟語は よみ＋いみ、まだの ものは ？？？？＋いみ（言葉さがしの 図鑑と 同じ 考え方）。
- てきとうに 長く なぞると 83%の ターンで チャンスに なる（ほぼ 毎ターン 問題が 出る）。多すぎると 感じたら `skillsOf()` の 条件を きびしく する。
- 敵 HP は 約4〜5ばいに（`STAGES` の コメント参照）。プレイヤー HP は 100＋40×ワールド。

  sfx.js に ない 関数は 何も 鳴らない（まどぐち `sfx` が 安全に とばす）。

## その3（2026-10-06）: 四字熟語を 210語に・よみあげ・れんけつは 3つ以上
- `YOJI` を 65 → **210語**（ゲームに かんけい なくても 響きで おぼえられる もの: 三日坊主・四捨五入・老若男女・森羅万象…）。
  □の 問題で「々」は □に しない（`makeYojiQ`）。400問 生成して 崩れ 0。
- **よみあげは 必殺技の ときだけ・男の 声**（2026-10-06 ユーザー依頼）: 読むのは `yojiCutIn()` の「ひっさつ、◯◯」だけ。答えあわせ・ずかん🔊・エンディングの よみあげは 外した。
  声は `MALE_VOICES`（Otoya→Hattori→Reed→Eddy→Rocko→Grandpa）の じゅんで さがし、なければ 女の 声を pitch 0.6 で。Mac では Reed が えらばれた。
- （以下は 最初の しくみ）**よみあげ**（`speak()`）: Web Speech API。端末の 日本語の 声（iPad/Mac は Kyoko＝ローカル）を ゆうせん、ネット・APIキー不要。
  **漢字では なく ひらがなの よみを 読ませる**（読みまちがい防止）。答えあわせ・四字熟語の カットイン（「ひっさつ、◯◯」）・ずかんの カード（🔊）で 読む。
  iOS は さいしょの 発声が タップの 中で ないと 鳴らないので、▶あそぶ で 空の 発声を して 起こしている。🔇 で 止まる。
- **れんけつ必殺技は 1本の 線に 3つ以上**（`CHAIN_MIN`=3）。3つ トリプルライン／4つ クアトロライン／5つ以上 ゴイセン・ストーム。
  ユーザーの 言葉「3語以上の言葉か その線の中に3つの言葉」→ ながことば=3もじ以上（すえおき）と 解釈した。ちがったら `skillsOf()` を 直す。
- これで チャンスは てきとう9〜12もじで 67%（前 83%）、正解率5わり 94／全問正解 147 ダメージ/ターン（はじめてボーナス別）。HP は すえおき。

## しくみの かなめ
- 6×5 盤を 8方向に なぞる（12もじまで）。**なぞった 列の とちゅうの ことばも 見つかる**（`wordsInTrace()`・長い ことば ゆうせんの DP）。
- 盤には 子どもむけ辞書（A）の 3〜5もじの ことばを しこむ（`pickPlantWord`・2もじは ぐうぜん できるので しこまない）。
  つくれる ことばが 6こ未満なら「もじを いれかえ！」。
- **必殺技**（`LONG_SKILL` / `CHAIN_SKILL` / `skillsOf()`）
  | | Lv1 | Lv2 | Lv3 |
  |---|---|---|---|
  | ⚔ ながことば（いちばん長い ことば） | 3もじ ことだまスラッシュ ×1.5 | 4もじ ゴイ・バースト ×2 | 5もじ以上 ゴイセン・ファイナル ×3 |
  | ⚡ れんけつ（1本の 線の ことばの数） | 2つ ダブルライン ×1.5 | 3つ トリプルライン ×2 | 4つ以上 ゴイセン・ストーム ×3 |
  ※いまは 上の 表は「チャンスの 出かた」と「ばいりつの もと」。実際の ダメージは 四字熟語チャンスの 節を 見ること。
  当たる えんしゅつ（`skillHit()`）: きりさき1回＋れんけつなら ことばの数だけ 連打。`cutIn()` は いまは つかっていない。
- てきの 特技: `min3`（2もじ むこう）・`armor`（れんけつ必殺技で ないと はんぶん）。

## じしょ（goi-data.js = build-goi.mjs の 生成物。手で 直さない）
`node goisen/build-goi.mjs` → index.html の `goi-data.js?v=N` と sw.js の CACHE を 繰り上げ。
- 材料（上ほど 優先）: `words-extra.txt`（手書き）→ 漢字の冒険の quiz → しりとりの 辞書（ここまで A＝子どもむけの いみ）
  → 言葉さがしの 大辞書 `kotobasagashi/kotoba-dict.js`（B＝ウィクショナリーの いみ）
- 2026-10-06: よみ 43295こ（A 5580／B 37715）・3.2MB。起動時の 展開は 約80ms。
- **いみを 出せない ことばは 入れない**（言葉さがしと 同じ 方針）。
- **2もじは A に ある ものだけ**。B の 2もじまで 入れると となり2マスの 65%が ことばに なり、れんけつ必殺技が タダで 出るため。
- **子どもに 出したくない 俗語は `NG_SURFACE` に 書きかたで 足す**（例: タイマン）。大辞書の 不適切語403語は 言葉さがし側で 除外ずみ。
  B の 3.7万語は 人の目で 全部は 見ていない。見つけたら ここに 足して つくりなおす（減らさない）。
