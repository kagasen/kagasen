## 問題の作り方（答えを人が用意しない）
`buildTasu / buildHiku / buildKake1 / buildKake2 / buildWaru` が、筆算の形（セル）・入力の順番（steps）・
くりあがり／くりさがりの小さい数字（mark）まで **計算で** 出す。
- ひきざんの くりさがり: その けたを とくときに 「16」「9」「7」のように 上に出し、元の数に ななめ線。0 を またぐ連鎖（806−248 等）も対応
- かけざん: くりあがりは かけられる数の つぎの けたの 上に 小さく（ピンク）出す。★3（2けた×2けた）は 1だんめ→2だんめで 上の くりあがりを 入れかえ、さいごの たし算の くりあがりは こたえの すぐ上の行に 出す（2026-09-27 ユーザー要望）
- ひきざんで こたえの 上のけたが 0（3521−3408=113 など）のときは 教科書どおり 書かない。ただし だまって おわると「勝手に終わった」と感じるので、さいごの けたで「これが さいごの けた！」、おわったら「千の くらいは 0に なるので かかないよ」を出し、少し長く 止める（2026-09-27 ユーザー指摘）
- わりざん: たてる→かける→ひく→おろす。ひいて 0 のとき（途中）は 入力を とばして すぐ おろす。商に 0 が 立つ形も対応
- **2けたで わる** = わりざんの **★4〜★6**（`maxLv('waru')`=6。ほかの コースは ★3まで）。ユーザーの イメージが「わりざんの 星4つ目から」だったため、試作の 別コース `waru2` を やめて 統合（2026-09-27）
  - ★4 2けた÷2けた／★5 3けた÷2けた（しょう1けた）／★6 3けた÷2けた（しょう2けた・あまり）。ミックス ★2→わりざん★4、★3→★5 を まぜる（`mixQ` の 内部の 種類名 'waru2'）
  - セーブ移行: 試作の `best['waru2-N']` → `best['waru-(N+3)']`、`last.course==='waru2'` → `waru` の lv+3（`load()` 内）
  - `buildWaru` は わる数の けた数に あわせて 列を ずらす（1けた・2けた 共通）。ひいた のこりが 2けたでも 1けたずつ 入力
  - 2けたで わる ときの **かける** は 1けたずつ（例 3×5 → 3×2＋くりあがり1）。くりあがりは となりの ますの 左上に 小さく（`corner:true` の mark）出し、かけおわったら けす
  - たてるの ヒントは「十のくらい どうしで 見当」
- わりざんの **ひく** は 1けたずつ（1けた・2けたで わる 共通・`subSteps()`）。くりさがりは ひかれる数の 右上に 小さく（`sup:true` の mark）、もとの 数に ななめ線。0 を またぐ くりさがりも ひきざんと 同じ。ヒントは けたごと（例 13 − 5）（2026-09-27 ユーザー要望）
  検証: わる数2〜99 × わられる数〜999 の 全問で、ひく の 各けたの ヒント（くりさがり後の数 − ひく数）＝ 入力する答え を 確認
- **しょうが かたよらない 出題**（2026-09-27 ユーザー指摘「さいしょに たてる数が 1か2 ばかり」）: ★4・★5 は しょう 2〜9 を 先に 同じ かくりつで きめてから わる数を えらぶ。★6 は さいしょに たてる数（しょうの 十のくらい）を 1〜9 から 同じ かくりつで。3000問ずつの 分布で ほぼ 均等を 確認
  - 検証: わる数10〜99 × わられる数〜999 の 全 85,095問 と 1けたで わる 全問で しょう・あまりが 一致、入力セルの かさなりなし
- 検証: ブラウザのコンソールで `HISSAN.build.*` を 数千問まわし、入力した数字を ならべると 正しい答え・あまり になることを確認ずみ（2026-09-27）

## ポイント（🔥フィーバー）と ランク（2026-09-27 第3段で 作りなおし）
- **log10 で持つ**（BigInt は ES2020 なので 使わない）。表示は 万〜無量大数（`UNITS`）。上限は 無量大数
- **はやさ しだい**: 1けた せいかい ごとに `k × gain(はやさ, れんぞく)` けた ふえる。はやさは その けたが 出てから `fastT(lv)`（★1 0.9びょう、★ごとに＋0.25）いないなら 1、そこから 3びょうで 0。おそいと ほとんど ふえない。はやい ときは「⚡」
- **ミスで へる**: `MISS_DOWN`=1.5けた（約30分の1）。れんぞくも 0 に。ユーザー要望（ゲームの 中の 点だけ。ランクの きろくは へらない）
- **コースで 上限を そろえる** `k`: きほんは 8もんの けた数の 合計で、エクストラは 30びょうで とける けた数の めやすで ならす（けたが 多い コースだけ 上に いきやすい、を ふせぐ）
- **バランス**（ブラウザで ★ごとに 8もん＋エクストラを まねして 調整）: fastT ぴったり・ミスなしで 無量大数に ぎりぎり／2%ミスで へいきん 恒河沙あたり／少し おそい＋3%ミスで 溝あたり／ゆっくり＋8%ミスで 万〜億。実機で 1けた1びょう・ミスなしの きほん8もん（たしざん★1）で 穣 まで を 確認
- 10れんぞくで「🔥フィーバー タイム！」は 演出だけ（れんぞくが のびるほど ふえる しくみ なので 別の ボーナスは なし）
- **ランクずかん**（🏅ランク ボタン）: コース×★（わりざんは ★6まで）ごとに たどりついた くらいを `S.rank['tasu-1']` に 保存（単調増加）。ぼうが その くらいまで 色つき。下に くらいの じゅんばん（1のあとに 0が 何こ）。旧 `maxUnit` は のこしてある（コースを 分けない さいこう）
- けっか画面に「たしざん ★1 の ランク 穣（じょう）🏅ランク アップ！」、タイトルの コースに 🏅ランク

### 追加（2026-10-06 夜・ユーザー試遊から）
