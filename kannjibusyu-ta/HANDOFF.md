# kannjibusyu-ta — 引き継ぎメモ

## 脱CDN（2026-07-06・完全オフライン化）
- `tailwind.css` … Tailwind CDN の置き換え。**使用クラスだけの静的ビルド**。
  新しい Tailwind クラスを書いたら再生成:
  ```
  printf '@tailwind base;\n@tailwind components;\n@tailwind utilities;\n' > /tmp/tw.css
  npx tailwindcss@3.4.17 -i /tmp/tw.css -o kannjibusyu-ta/tailwind.css --content "kannjibusyu-ta/**/*.html" --minify
  ```
- フォント … Google Fonts CDN をやめて**システムフォント**へ置換（任意の入力文字を表示するアプリのためサブセット同梱は不可）。

## PWA化（2026-07-07・全アプリ一括）
- `manifest.json` / `sw.js` / `icon.svg` を追加。エントリHTMLに theme-color / manifest / apple-touch-icon / SW登録（http(s)のみ・file://では登録しない）を追記。
- SWキャッシュ名は「(アプリID)-cache-v1」。ローカルアセット全部をプリキャッシュ（ネットワーク優先・失敗時キャッシュ）。**アセットを更新したら sw.js の CACHE を繰り上げ、ASSETS の顔ぶれも見直す**こと。
- **注意: Cache Storage は同一オリジン（GitHub Pages）で全アプリ共有**。activate の古キャッシュ掃除は自アプリのプレフィックス（`(アプリID)-cache-`）だけを対象にしてある。`k !== CACHE` だけの条件に戻すと他アプリのオフラインキャッシュを消してしまうので戻さない。

## index.html 化（2026-07-07）
- 本体ファイルを `kanjibusyu-ta.html` → `index.html` にリネーム（フォルダURL直アクセスの404を解消、他アプリと同じ「フォルダ + index.html」の慣例に統一）。`apps.js` のリンク・`manifest.json` の `start_url`・`sw.js` の ASSETS とオフライン時ナビゲーションフォールバックを揃えて修正。sw.js の CACHE は v1→v2。

## ゲームが起動しないバグ修正（2026-07-07）
- **原因**: 2026-07-06 の脱CDNフォント置換で `const FONT_FAMILY = ''Hiragino Maru Gothic ProN', ...'` がクォート崩れの**構文エラー**になり、スクリプト全体（ゲーム本体）が死んでいた。置換でフォント列が二重になってもいた。
- **修正**: `"'Hiragino Maru Gothic ProN', 'Hiragino Kaku Gothic ProN', 'Hiragino Sans', Meiryo, sans-serif"` に修正（重複も解消）。sw.js CACHE v3。
- **検証**: canvas 全面描画・タップで TITLE→SELECT→PLAY 遷移を確認。console errorなし。
- **再発防止**: release-check.mjs の検査項目7（インラインJS構文チェック）で今後は自動検出。

## 「見えるところで当てる」ようにした + 完成度アップ（2026-09-06）

### 一番の変更: 判定ライン（JUDGE_LINE_Y = 170）
- **問題**: 弾が画面上端まで飛ぶので、敵が出てきた直後（HUDの裏・ほぼ画面外）で撃破されていた。
  連打すると「何が正解だったのか」が全く分からない、というのが今回の依頼の出発点。
- **対処**: `JUDGE_LINE_Y`（=170px）を境に、
  - 弾は `this.y - height/2 <= JUDGE_LINE_Y` で消える（ラインを越えない。当たると `judgeLineFlash` で光る）
  - 敵は `isHittable()`（全身がラインより下）が真のときだけ当たり判定に入る
  - 自機もラインより上へは行けない（上に隠れて無敵になるのを防ぐ）
  - ライン上部はグラデーションで暗くし、破線＋「▼ ここから下で あたる ▼」（最初の30秒だけ）で明示
- **検証**: レーザー（最速・vy=-25）で3000フレーム自動プレイし、撃破時のyの最小値＝190（=170+敵の高さ半分）。
  ラインより上での撃破はゼロ。

### 見逃しラインも見える位置に（MISS_LINE_Y = 780）
- 以前は `canvas.height + 50`（＝完全に画面外）で見逃し判定。何を逃したか分からなかった。
- 780（画面内）に変更し、ピンクの破線で表示。逃した瞬間に✕と「にがした！ ◯＋◯＝漢字」が出る。

### 画面まん中の結果バナー（resultBanner）
- 撃破位置に漢字を出す方式（Particle の 'kanji' 型）はやめ、**必ず同じ場所（y=285）**に出す方式へ。
  - 正解: `木 ＋ 寸 ＝ 村（むら）` ＋「せいかい！ ◯れんぞく！」
  - まちがい: `木 ＋ 皮 ？` ＋「「皮」は 氵 と くっつくよ → 波」（`findBushuFor()` でヒントを出す）
  - 見逃し/切りすぎ: 正しい合体漢字と読みを見せる
- **連打対策**: 最低 `RESULT_MIN_SHOW_FRAMES`(24f≒0.4秒) は表示。その間に来た正解は `resultQueue`（最大3件）に並べ、
  順番に見せる。まちがい・見逃しは待たずに割りこむ（すぐ知らせたいため）。
- Particle は「どの敵に当たったか」を示す〇✕・得点・爆発だけを担当し、位置は必ず画面内にクランプする。

### そのほか追加したもの
- **コンボ**: 正解の連続でボーナス（+20/連, 最大+200）。ミス・被弾で0。効果音も半音ずつ上がる。
- **ハイスコア**: `localStorage['kannjibusyu-ta:highscores:v1']` に**部首ごと**に保存。タイトル・部首えらび・ゲームオーバーで表示。
- **ゲームオーバーのふりかえり**: この回で「つくれた かんじ」（最大18こ・読みつき）と「にがした かんじ」（最大6こ）を一覧表示。
  学習アプリとして、遊んだあとに何を覚えたかが残るようにした。すぐタップで消えないよう1.2秒のガードあり。
- **ポーズ（⏸ / Pキー / Escape）**: 止まっていた時間ぶん `playStartTime` をずらすので、難易度アップのタイマーは進まない。
  タブを隠したら自動ポーズ。
- **音のオンオフ（🔊 / Mキー）**: `localStorage['kannjibusyu-ta:muted:v1']` に保存。
- **効果音追加**: 正解のピロリン（コンボで音が上がる）・ミスのブー・ハート回復のキラリン。
- **敵の重なり回避**: 出現時に他の敵と80px以内なら8回まで位置を引き直す（つくりの字が読めるように）。
- **部首えらび画面**: つくれる漢字の数・部首ごとのハイスコア・武器の説明を追加（パネルは 100x170 に拡大）。
  描画とタップ判定は `SELECT_PANEL_*` / `selectPanelX()` を共用（ズレ防止）。
- **刀ボタン**: 半径46に拡大＋クールダウンをリングで表示。
- sw.js の CACHE は v5 → **v6**。

### 触るときの注意
- `JUDGE_LINE_Y` を動かすと、弾の消える位置・敵の当たり判定・自機の上限・Particle のクランプ・HUDの暗幕が**全部**連動する。
  1箇所の定数で効くようにしてあるので、数値だけ変えれば良い（描画位置のベタ書きを増やさないこと）。
- 結果バナー（y=285）はラインのすぐ下。ここを動かすときは「▼ここから下であたる▼」の文字と重ならないか確認する。
