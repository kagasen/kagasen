# kotoba-puzzle（ことばパズルバトル）— 引き継ぎメモ

子ども用（学習・記録系）。**パズドラと 同じ 操作**の パズル＆バトルで、そろえるたびに 漢字の「部首の なかま」が 見えてくる。

## 経緯（2026-10-06）
1. **第1版「なぞり版」は ボツ**: もじ盤を なぞって ことばを つくる 方式。ユーザー評価
   「全く面白くない。言葉が難しくて作れない。パズドラみたいに玉が動く感じもない」。
   → **ことばを つくらせる のは 難しすぎる**／**玉を もって うごかす 気もちよさ が 本体** という 教訓。
   旧コードは 残していない（セーブの v1 は load() で うつす）。
2. **第2版（いま）**: ユーザー提案「ジャンルを絞るのもいい」→ **部首の なかま** に しぼった。
   - あそびは「同じ いろを 3つ そろえる」だけ（漢字が 読めなくても あそべる）
   - 玉の いろ = 部首の なかま、玉に 書いてある 字 = その なかまの 漢字
   - けすたびに「💧さんずいの なかま：海（うみ）・池（いけ）…」が 出る → しらないうちに 部首の いみが 身につく

## しくみ（パズドラ準拠）
- 6×5 盤。玉を 1つ もって うごかすと、とおった 玉と いれかわる（ななめ OK）。さいしょに いれかえた 瞬間から **6びょう**（`MOVE_MS`、パズドラは4秒）。
- たて・よこ 3つ以上で きえる。くっついた 同じ色は 1コンボ（`findGroups`）。おちて きた 玉で また そろえば 落ちコン。
- 盤は さいしょ そろっていない（`makeBoard`）。上から ふる 玉は うんまかせ。
- ななめ移動で となりを ひろわないよう、マスの まんなか ちかく（半径0.47）だけ 反応。はやく うごかしても 1マスずつ いれかえる。

## 部首の なかま（kanji-data.js = build-kanji.mjs の 生成物。手で 直さない）
| 玉 | 部首 | 字 |
|---|---|---|
| 💧青 | 氵さんずい | 池海汽活泳… 20字 |
| 🌳緑 | 木きへん | 林森村校板… 20字 |
| 🔥赤 | 火・灬 | 火灯炭焼熱照点然無災 10字 |
| ☀黄 | 日 | 日明晴時曜… 17字 |
| 💬紫 | 言ごんべん | 記計語読話… 19字 |
| ❤ピンク | 心 | 心思悲意感…（かいふく玉）16字 |
- 字の よみ・ことば・いみ は 漢字の冒険（kanji-bouken/gradeN-data.js）から。字を 足すときは `build-kanji.mjs` の FAMILIES を 直して
  `node kotoba-puzzle/build-kanji.mjs` → index.html の `kanji-data.js?v=N` と sw.js の CACHE を 繰り上げ。
- ワールド1は 💧🌳🔥❤ の 4色（そろえやすい）、2で ☀、3で 💬 が くわわる。はじめて 出会う なかまは しょうかい画面が 出る（`S.fams`）。

## 数値（ぜんぶ 叩き台）
- ダメージ: 1グループ `15×n×(1+0.25×(n-3))`、コンボ倍率 `1+0.25×(コンボ-1)`、てきの にがて（`WEAK`: 火←💧, 水←🌳, 木←🔥, 日↔言）×2。
- ❤ は 6×n 回復（コンボ倍率あり）。プレイヤーHP 100。
- シミュレーション（ブラウザ、ランダムに うごかす）: 4色＝平均1.6コンボ/127ダメージ、6色＝0.5コンボ/25ダメージ。
  ねらって うごかす（30通りから いちばん いい手）: 4色 7.6コンボ、6色 3.1コンボ/227ダメージ。
  → W1 は 適当でも かてる、W3 以降は ねらう ひつようが ある。W4・W5 の HP は 下げてある。実機で 調整。
