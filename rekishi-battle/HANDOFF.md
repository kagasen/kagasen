    ひっさつのカットインも 何も見えない）。「画面が見えません」は これのこと。

- ★★★**BGMを ほんものの和楽器の曲に 差しかえ（2026-08-11）**
  ユーザー:「ゲームの音楽ですが、64ビットとかではなく、フリーの何か歴史感のあるものとか
  ないですか。一気にチープなゲームになってしまいます」→「ぴこぴこは綺麗に削除してください」。
  ・**ピコピコの曲は 全部消した**（`SONGS` の音符表・`bgmNote`／`bgmDrum`／`bgmPump`／
    `bgmPrep`／`midiHz` など **319行**）。★もどさないこと。
  ・**曲＝甘茶の音楽工房のフリー素材**（mp3を同梱。CDN読み込みではないので §1 は まもられている）
      ホーム … 「弥生の空に」   `bgm/home_yayoinosorani.mp3`（1分48秒・1.3MB）
      バトル … 「幕末舞曲〜戦〜」`bgm/battle_bakumatsubukyoku_ikusa.mp3`（2分24秒・1.7MB）
  ・**利用規約**（https://amachamusic.chagasi.com/terms.html を確認ずみ）:
    ゲームのBGMに使ってよい／クレジット任意／使用報告 不要。
    **禁止＝音楽だけを取り出しての配布・販売／JASRAC等への登録／作曲者をいつわる**。
    ★§7 のとおり **ホーム下に クレジットを常設**（`.credit`）。**消さないこと**。
  ・**加工の手順**（曲を差しかえるときも同じ。手で いじらず これで 作りなおす）:
    `ffmpeg -i 元.mp3 -ss 0.45 -to <おわり> -af "afade=t=in:st=0.45:d=0.06,afade=t=out:st=<おわり-0.3>:d=0.30" -c:a libmp3lame -b:a 96k -ar 44100 -ac 2 元は128kbps/4.0MB → **96kbpsで 3.0MB**`
    ★おわりの **無音3〜4秒を 切る**のが かんじん（切らないと ループのたびに 無音が入る）。
      無音の 始まりは `ffmpeg -af silencedetect=noise=-50dB:d=0.4` で しらべる。
  ★★★**音量は かならず GainNode**。`audio.volume` は **iPad(iOS)では きかない**。
    ここを まちがえると 教室で いきなり 大音量になる。
  ★★**iOS対策 `bgmUnlockAll()`**: 最初のタップの **その場で** 2曲とも play()→pause() する。
    `setTimeout` の中に入れると「指の外」になり、バトル→ホームの 曲もどりが 鳴らない。
  ・**こうか音(SFX)は そのまま**（tone()のピコピコ）。消すと 押した手ごたえが なくなるため。
    気になるなら フリーの効果音素材に 差しかえる（未着手）。
  ✅実測（Chromeで通し確認）: ホーム↔バトルの きりかえで **2曲が かさならない**（前の曲は
    0.6秒で しぼって pause・位置は のこるので もどると つづきから）／🎵オフ→止まる・オン→もどる／
    🔊オフで 曲も止まる・オンで もどる／**ループする**（おわり2秒前から 待って 頭に もどるのを確認）／
    たたかう！→ 曲が battle に 変わる／console エラーなし／`node release-check.mjs` エラー0。
  ⚠️まだ: **ループの つなぎめ**は 曲の おわり（ちゃんと終わる曲）→ 頭 に もどる形。
    無音は 切ってあるが「1回 終わって また始まる」感じは のこる。気になると 言われたら
    **イントロを とばして 途中から ループ**（loopStart相当）を 足す。

【人物が左を向いてしまうとき＝FACE_FIX（2026-08-06・ユーザー指摘で追加）】
 - 症状: バトルでもずかんでも その人だけ 反対（左）を向いている。行基と東郷平八郎で起きた。
 - 原因: 向きの自動判定 facing() は「顔（肌色）と 髪・帽子（暗い色）のどちらが右か」で決めている。
   **ぼうず頭（髪が無い）・白い軍帽（暗くない）** だと材料が足りずに外れる。
 - 直しかた: build-sprites.py の **FACE_FIX** にその人を書いて、その人だけ作りなおす。
   `python3 build-sprites.py gyoki togo` （走ると ASSET_V が自動で上がる）。
     "flip" … 元絵が左向きなのに facing が気づけない → かならず反転する（東郷平八郎）
     "keep" … 元絵はもう右向きなのに facing が「左」と外す → ぜったいに反転しない（行基）
     {"atk": "keep"} … そのコマだけ直す
 - ★**こうげきのコマ(atk)だけ外れる人が多い**（近松門左衛門・小野妹子・大隈重信・雪舟＝keep、
   陸奥宗光＝flip）。技のエフェクトの光や、顔をかたむけたポーズで 肌色・暗い色の重心がずれるため。
   **たち・あるきが合っていても こうげきは別**なので、4コマぜんぶ見ること。
 - ★**元のシートの中でコマごとに向きがちがう人がいる**（東郷平八郎＝たちだけ左向き、
   あるき・こうげきは右向き）。人まるごと "flip" と書くと、もともと右向きのコマまで逆にしてしまう。
   → `"togo": {"stand": "flip", "walk": "keep", "atk": "keep"}` のように**コマごとに**書くこと
   （2026-08-06にユーザー指摘。まるごと flip にして あるきとこうげきを壊した）。
 - ★どちらを書くかは **生成時のログ**を見れば迷わない:
     ログが「atk:左→反転」＝もう反転している → それでも左向きなら **"keep"**

【人物の大きさ（2026-07-30・ユーザー指摘「中臣鎌足が小さく感じる」から2段階で直した）】
 ★スプライトの大きさは **build-sprites.py の FIGURE_FRAC / FOOT_RATIO** と
   **index.html の .unit .sprite img の 142% / -22.3%** の**4つがワンセット**。
   片方だけ変えると全員が浮く・めり込む・大きさが変わるので、必ずセットで直すこと。
 ★**人物ごとの大きさの手直しは build-sprites.py の SIZE_ADJUST でやる**（CSSはさわらない）。
   1.0が手直しなし。数字を変えたらその人だけ生成しなおせばよい。
   いまの中身:
     itagaki=1.16    … 赤い旗が頭のすぐ横にあり、頭とつながって太く測られるため戻した
     okuma=0.865     … ユーザー指摘で小さくした（7/30に0.91→8/3にもう少し）。頭だけ大きく
                       描かれた絵で、体の面積は42人でいちばん小さい（0.77倍）のに頭は64あった
     chikamatsu=0.93 … ユーザー指摘（8/3）。頭のはばは54で平均的だが全体のボリュームが大きい
     meiji=0.93      … 同上（8/3）
   ★頭のはばが平均的でも「大きい」と言われることがある（近松門左衛門・明治天皇）。
     そのときは頭ではなく背たけ・全体の量感の問題なので、素直にここの数字で下げる。
   ★「大きい／小さい」の見え方は**頭の大きさ**でほぼ決まる（面積や肩はばでは説明がつかない。
     大隈重信は面積最小なのに大きく見えていた）。手直しするときは頭のはばを見ること。
     目安: 頭のはばが 54〜58 におさまっていれば そろって見える（256pxのスプライトで測った値）。

 ■ 第2段: 高さをそろえただけでは足りなかった（頭の大きさ）
   高さを完全にそろえても中臣鎌足はまだ小さく見えた。原因は**絵ごとに頭の描きかたが違う**こと。
   烏帽子のように背の高いかぶりものがあると、全高のうち帽子のぶんだけ体と顔が小さくなる。
   実測「頭のはば÷人物の高さ」= 中臣鎌足0.329 / 伊藤博文0.334 ↔ 大隈重信0.459（中央値0.3766）。
   → **HEAD_BLEND=0.5** で「高さ」と「頭の大きさ」を半分ずつ混ぜて補正する方式にした。
     0にすると高さだけ（＝第1段の状態）、1にすると頭はそろうが背たけがバラバラになる。
   結果: 人物の高さのひらき1.28倍・頭のはばのひらき1.57倍（補正前は1.86倍）。
     いちばん大きくした人 中大兄皇子×1.16 / 源頼朝×1.14、小さくした人 小村寿太郎×0.90 / 大隈重信×0.91。
   ★頭のはばは「上から45%の帯で、横につながっている いちばん長い部分の**70%点**」で測る。
     max だと笠や軍帽の つば を頭とみなす（伊能忠敬 max=89 / 70%点=66）。
     頭にくっついた持ち物までは分けられないので、そこは SIZE_ADJUST の出番。
 - もとの不具合: キャンバスの大きさを「その段の高さ」で決めていたため、頭上にエフェクトが
   のびている人ほど段が縦長になり、人物だけ小さく描き出されていた。
   実測で **最大1.40倍のひらき**（織田信長161px・中臣鎌足186px ↔ 北条時宗226px）。
   さらに「やられ」が低く描かれたシートでは立ちポーズが浮いていた（中臣鎌足は人物の21.5%ぶん）。
 ■ 第1段: 大きさと足元の基準を変えた
 - 直しかた: 大きさの基準を「たちコマの人物の高さ」、足元の基準を「たちコマの足元」に変えた。
   **足元の高さは42人ぴったり同じ**になった（ブラウザで実測。前は中臣鎌足だけ21.5%浮いていた）。
 - 比率の決めかた（人物の高さを1として実測）: 足元より上に必要なのは最大1.304（卑弥呼の後光）、
   下に必要なのは最大0.319（中臣鎌足のやられが低く描かれている）。
   → FIGURE_FRAC=0.60・FOOT_RATIO=0.20 なら1人も切れない。
   ★はみ出す絵があると生成時に「※注意」が出る。出たらこの2つを見直すこと（いまは0件）。
 - 表示側の142%は「人物を枠の85%に見せる」ため（=0.85/0.60）。85%は直す前の中央値なので、
   **全体の大きさ感は今までと変わらない**（小さかった人が大きくなっただけ）。
