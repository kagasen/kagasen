■ 第2弾: 色つきの光の中の模様を抜けるようにした（2026-07-28）
────────────────────────────────────────────────────────
中臣鎌足（白い刀の軌跡）と聖武天皇（金の後光）が処理できるようになった。効いたのは3つ:

① checker_score(): 「ななめT ずれた所は同じ色 / たて・よこT ずれた所はちがう色」という
   市松のせいしつだけで模様を見つける。**格子の位置合わせがいらない**のがミソ。
   格子は1200pxも行くと位置がズレるので、位置に頼る方式は全部だめだった。
   しきい値 CHECKER_HIT=0.40 は実測（背景0.5前後 / ふつうの絵0.3以下）から決めた。
② strip_lines(): 線の見わけを「画素の数」から「**ひとつづきに長くのびているか**」に変更。
   足元のすぐ上がこんでいるせいで聖武天皇の地面線を消しそこねていた。
③ blobs() の ds を 4→2 に。粗すぎて 中臣鎌足の刀の軌跡と やられのコマ、
   紫式部のとなり合うコマがくっついていた。1枚あたり3〜4秒になるが許容。

- strip_edges(): コマのふちに沿う まっすぐな線を消す（小野妹子の地面線が消えた）。
  まん中を通る刀を消さないよう、ふちの数pxだけを見る。
- CELL_PICK に (3,4) のような書き方を追加＝その2コマを合体させる。
  平清盛の赤い斬げきの光がはなれたかたまりになったので、人物とくっつけるのに使った。

★★ 試して だめだった 方法（またやらないこと）★★
- 半透明復元を全面にかける → 絵の柄で Pd と Pl が食いちがい、髪や顔が溶けてぼやける
- まわりとの明暗差だけで模様を判定 → 髪・帽子・足のふちが同じくらい反応して分離できない
- 上を「大きなかたまりだけ」に絞る → それでも顔に穴があく
- コマわくの中の白地をふちから塗りつぶす → 対象がほとんど無く効果なし（消した）
- 到達できる背景を alpha から広げる → 背景に灰色のもやが残り、かえって汚くなる

■ クイズ・排出・ステータスの見直し（2026-07-28・実際に遊んだユーザーの指摘5点）
────────────────────────────────────────────────────────
指摘: ①3問目が出ないことがある ②問題が同じものばかり ③その時代のカードが出てほしい
      ④レアが出すぎ ⑤みんな満遍なく強くて簡単にクリアできる

① 3問目が出ない — 原因は REKISHI_QUIZ が st1/st2/st3 にしか無かったこと。
   startQuiz() は「人物あて2問＋時代問題2問から3問」を作っていたので、時代問題が0の
   14ステージでは2問しか作れない。それでも renderQuiz() 側が `state.quiz.i === 2` と
   直に書いていたため、2問目のボタンが「つぎへ」のままになり、押すと qs[2] が undefined で
   例外＝画面が止まる、という出かたをしていた。
   直しかたは2つとも入れた:
     - REKISHI_QUIZ を全17ステージぶん用意（合計107問）
     - 問題数は `qs.length` から見るように変更（データが薄くても止まらない）

② 問題が同じものばかり — 型を2つ→4つに増やした。
     ① 業績→だれ？（従来）  ② 人物→したことは？（①の逆引き・新）
     ③ 人物→何時代？（新）   ④ REKISHI_QUIZ（先生の問題）
   ①〜③は人物データから自動で作るので、人物を足せば問題も増える（CLAUDE.md §8）。
   出題は4つの型から順ぐりに1問ずつ取る方式にして、型のかたよりも無くした。
   実測: 1ステージあたり13〜32種類（もとは4〜7種類、うち14ステージは壊れていた）。
   ③の選択肢は「平安時代」と「平安時代の末」のように**前方一致する時代は並べない**
   （otherEras）。まぎらわしすぎて正解が決まらなくなるため。

③ カードの排出 — pick(CHARS) を「そのステージの時代の人物 85%（ERA_DROP）」に変更。
   ★設計合意の「全42人からいきなりランダム」を**ユーザー指示で**変えた点に注意。
   人数が3人に満たない時代だけ、時代順にとなりへ広げて3人にする（CHARS が時代順なので
   前後に足すだけでよい）。広げる下限を5人にすると奈良(3人)にまで他の時代が混ざって
   ねらいがぼやけたので3人にした。
   実測の「ぴったり同じ時代」率: 大半のステージで86〜90%。
   低いのは弥生29%（卑弥呼ひとりしかいない）・鎌倉57%・戦国57%（2人ずつ）。これは人数の問題。

④ レア確率 — 2問正解30%→12% / 3問正解60%→25%（R_CHANCE）。0〜1問正解のN確定は据え置き。

⑤ ステータスの極端化 — statMul() を 0.55+★×0.15（0.7〜1.3倍）から
   0.25+★×0.25（0.5〜1.5倍）へ。上下の幅が1.86倍→3倍になった。
   あわせて REKISHI_STATS の42人**全員**を作り直し、4つのルールを課した:
     ① 全員に弱点(1か2) ② 全員に強み(4か5) ③ 合計8〜11 ④ 4-4-4型と組み合わせの重複は無し
   聖徳太子 4-4-4 のような「全部そこそこ」が指摘の正体だったため。
   結果の例: 陸奥宗光 HP100/こうげき33/はやさ54 ↔ 鑑真 HP360/こうげき6/はやさ34。
   HPの開きは 2.2倍→3.6倍になった。

★★ 正直な結果: ⑤をやっても難易度はほとんど変わらなかった ★★
   自動プレイで17ステージ全部、スターター3枚(卑弥呼・聖徳太子・織田信長)で勝ててしまい、
   みかたの城は一度も削られなかった（旧倍率でも新倍率でも所要70〜90秒でほぼ同じ）。
   理由は個性ではなく**おかねの経済**。income 10/秒に対しコストが65〜90なので、
   出しつづければ数で押しきれてしまい、個々の弱点が表に出ない。
   個性そのものは効いている（1人だけのデッキで試すと、聖徳太子は勝ち、
   源義経・鑑真・歌川広重は城を割られて負ける）。
   次に難しくするなら income / minion.every / minion.max / boss の位置。★ユーザーと相談。

■ 「出しつづければ勝てる」を壊す（2026-07-28・ユーザーの指摘）
────────────────────────────────────────────────────────
指摘:「とにかくキャラを出し続けたらクリアするというのは面白くない。プレイヤーが
      育てている・選択している感がほしい。必殺技や、レアにすると勝てるようになる形は？」

【まず数字で原因を特定した】
自動プレイの実測で **味方が1体も死んでいなかった**（st17で29体出撃して戦死0・城100%）。
ざこは同時4〜6体までしか湧かず、ボスは前に出ない（speed 10）。つまり
**敵の圧は時間で増えないのに味方だけ積み上がる**＝消耗ゼロ。
だから前回スタッツを極端にしても難易度が変わらなかった（弱点が表に出る場面が来ない）。
→ 「敵を強くする」ではなく「消耗と、選ぶ場面を作る」が正しい手当てだと判断。
ユーザーと相談し、第1(消耗)→第2(必殺ゲージ)→第3(レア度で技解放) の順で合意。

【第1: 消耗をつくる】
- ざこ敵をウェーブ制に。「まとまって来る → 休み → もっと大きい波」。
  体数は minion.max から自動計算（waveSize）なので、ステージを足しても何も書かなくてよい。
- おかねの入れもの(moneyCap)が戦闘中に育つ方式に。150から8秒ごとに+25。
  もとは最初から999で、ためる意味がまったく無かった。
- ★これだけで味方が戦死するようになり、ノーマルのみのデッキは中盤以降で負けるようになった。

【第2: ひっさつゲージ】
- 共有ゲージ1本。満タンで画面下の帯が顔ボタン列に変わり、**場に出ている人物**から選んで撃つ。
  ★キャラごとのゲージにしなかったのは、20体以上いる画面でiPadの指では狙えないから。
    押す場所がいつも同じなので迷わない（ユーザーと相談して決定）。
- ★つまずき2つ（どちらも実測で発覚し、直した）:
  ① 必殺技が敵の町(ebase)にも効いていた → レア5人で**13秒でクリア**してしまい、
     「誰で撃つか」が「一番ダメージが大きいのを撃つ」に縮んだ。
     → 必殺技は町に効かないようにした。必殺は**戦線を押し返す道具**、町は歩いて行ってこわす。
  ② ゲージを「与えたダメージ」でためていた → 味方が増えるほど早くたまり、
     **68秒の戦闘で24回**も撃ててしまって特別感ゼロ。
     → 「時間(22秒)＋受けたダメージ」に変更。さらに1秒あたりの上のせに上限をかけた
       （味方が増えると被弾も増えるため）。いまは1戦で2〜7回。

【第3: レア度で技が増える】
- skill/skill2/skill3 は42人ぶん最初からデータにあったのに未実装だった。
  N=1つ / R=2つ / SR=3つ を実装。自動発動は**順ぐりに**出す（レアほど多くの業績名が見られる＝学習）。
  ひっさつは**いちばん上の技**を使うので、進化すると必殺技の名前と威力が変わる。
  実測: 織田信長 N「桶狭間の戦い」→ R「長篠の戦い」→ SR「天下布武」。
- lvMult に進化ジャンプを追加: Lv4=1.15倍 → Lv5(レア)=**1.50倍**、Lv29=2.70倍 → Lv30(SR)=**3.25倍**。
  もとは1レベル+5%だけで、ノーマルLv4→レアLv5が 1.15→1.20倍＝ほぼ変化なしだった。
  ★今より下がる値は1つも作っていない（育てた記録が弱くならないこと。CLAUDE.md §3）。

【自動技を弱くした（SKILL_EVERY 12→16秒・倍率も引き下げ）】
最初の実装では必殺技を1回も撃たなくても勝ててしまった（○64秒・城100%・必殺0回）。
原因は**自動発動の技が強すぎた**こと。10体出ていると1秒に1回くらい自動で技が出て、
それだけで勝負がついていた。力を「勝手に出る技」から「選んで撃つ必殺技」へ移した。

【実測の結果（自動プレイ・3人/5人デッキ）】
- st9 レア5人: 必殺なし=**負け**(城0%) / 必殺あり=**勝ち** ← ねらいどおりの形が出た
- 3人スターターデッキ: N は st7以降 全滅 → R にすると勝てる（st7 N=×46秒 / R=○76秒）
- 必殺技の回数は1戦2〜7回（もとは24回）
- 敵の町は必殺技で削れない（850→850 を確認）

【正直な残り課題（HANDOFF にも書いた）】
- **必殺技が勝敗を分けたのは st9 だけ**。他のステージはまだ撃たなくても勝てる。
  もっと効かせるなら SKILL_MULT をさらに下げるか WAVE_REST を短くする。
- st5(奈良)は era プールが こうげきの低い3人なので戦闘が90〜130秒と長い。
- st9(戦国)は まもり1〜2の3人なので、その時代デッキだけだと苦しい
  （※極端ステータスが効いている証拠でもある。守り役を混ぜれば勝てる）。
- 17ステージの数値は叩き台のまま。実機で遊んで調整するのが前提。

【その他の直し】
- ざこ敵は名前を出さないようにした。波でまとめて出ると「今川の兵今川の兵…」と重なって
  読めなかったうえ、全員おなじ名前で学習の役に立たないため（ボスの名前は残す）。
- tick の dt に下限0を入れた。時計が巻きもどるとおかねや時間がマイナスに進むため（保険）。
