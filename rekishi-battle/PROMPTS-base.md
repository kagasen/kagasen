■ 使い方（①②③）
────────────────────────────────────────────────────────
1. 下のプロンプトを そのままコピペして生成する（参考画像は いらない）。
2. 出てきたPNGを **`sheets/base_{id}.png`** という名前で保存する（id は各見出しの `/` のあとの英字）。
3. `python3 build-bases.py` を走らせる。
   → マゼンタの背景をぬいて・まわりの余白を切って・大きさをそろえて
     `images/bases/{id}.webp` に書き出す。ASSET_V も自動で上がる。
   → 1枚だけ作りなおしたいときは `python3 build-bases.py tenshu` のように id を書く。
4. ゲーム側の配線は **もう入っている**（§配線ずみ）。ファイルを置いた瞬間に絵になる。
   絵が無い・読めない id は 今までどおり絵文字のまま出る（設計合意7の流儀）。

★**背景は「透明」ではなく `#FF00FF` のマゼンタ一色** で頼むこと（敵の絵と同じ理由）。
  透明（＝グレーの市松）で頼むと、金色の屋根・炎・水しぶきのような
  **色つきの半とうめい**の中に 市松がそのまま残る。マゼンタなら確実に抜ける。

★**建物の いちばん下（地面につく所）を 絵の下ばしに そろえる**ように頼むこと。
  build-bases.py は「切りぬいた絵の いちばん下＝地面の線」として置くので、
  下に影や草を描かれると **城が浮いて見える**。

★**ぜんぶ「右向き」で描く**（人物・敵と同じ約束）。
  敵がわの絵は 表示のときに ゲームが左右反転する（`.unit.enemy .sprite`）。
  だから **敵の船・陣も 右向きで描く**。「敵だから左向き」と書くと 反転されて逆になる。
  左右対称の建物（やしき・やくしょ・かべ）は 反転しても分からないので気にしなくてよい。

■ 絵にするときの約束（ユーザーと決めたこと。くずさない）
────────────────────────────────────────────────────────
- ★**国や民族をまるごと悪者にしない**（PROMPTS-enemy.md と同じ線引き）。
  元軍の船・黒船は「**乗り物**」として ふつうに かっこよく描く。
  どくろ・血・こわい顔・ぼろぼろの旗のような「悪の砦」らしい味つけをしない。
- ★**本物の紋《もん》は 相手を見わけるためだけに使う**（桔梗紋＝明智、大一大万大吉＝石田）。
  ざこの旗を無地にしてあるのと同じ考えで、**紋は 城のほうで見せる**。
- ★**人を描かない**（建物と乗り物だけ）。人を描くと、ユニットと同じ大きさに縮んだときに
  「敵の兵が城にくっついている」ように見えて、味方が攻めている場所が分からなくなる。
- ★**炎・煙・こわれかけの表現は ひかえめに**。城のHPが満タンのときの絵なので、
  はじめから燃えていると「もうこわれている」と かんちがいされる。
- 小学生が見て「何の建物か」が分かること（CLAUDE.md §5）。細かい模様よりシルエット。

────────────────────────────────────────────────────────
■ ★大きさの約束（ここを外すと 城だけ 浮く・めり込む）
────────────────────────────────────────────────────────
- build-bases.py が **正方形（512×512）**に そろえて書き出す。
  そのとき「切りぬいた絵」を **たて 88%・よこ 92% におさまるように縮めて、
  下ばしに くっつけて 横まん中**に置く。
- index.html の CSS はこの約束とペア:
    `.unit.base.has-sprite .sprite img { width:190%; height:190%; bottom:0 }`
    `.unit.base.has-sprite .hpbar { margin-bottom: calc(var(--unit-w)*0.76 + 4px) }`
  → 画面では **たて およそ180px**（人物は88px なので **人の2倍**）。
  ★片方だけ変えないこと。88% を変えたら hpbar の 0.76 も 変える。
- ★**よこに長い絵（船・かべ）は、画面のはしで 30pxほど 切れる**（実測。PC幅672px）。
  城は画面の左右のはしに立つので、これは わざと（城が画面の外へ つづいて見える）。
  ★だから **見せたい所を 絵の左右のはしに置かない**。船の先を右向きにそろえてあるのは
    「切れるのは いつも 船の うしろ」にするため。
  ★これを直そうとして 城を内がわへ ずらすと、こんどは 矢(ゆみ)の とどく距離を
    さらに けずることになる（城の絵に 矢が かかってしまうため）。ずらさないのが正解。
- だから **プロンプトに「大きく描いて」と書いても効かない**（敵のボスと同じ話）。
  大きさを変えたいときは CSS の 190% を さわる。
