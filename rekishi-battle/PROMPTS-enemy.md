★味方42人ぶんは PROMPTS-pose.md。こちらは**敵（ボス17体・ざこ12種）**。
★絵の作りかた・落とし穴の理屈は PROMPTS-pose.md と同じなので、先にあちらの「■背景について」を読むこと。

────────────────────────────────────────────────────────
■ 使い方
────────────────────────────────────────────────────────
- 1体につき1回の生成で「4コマならんだポーズシート」を作る。**全部で29回**（ボス17＋ざこ12）。
- 味方とちがい **参考画像は無い**。プロンプトの中に見た目をぜんぶ書いてあるので、そのままコピペするだけ。
- 出てきたPNGを `sheets/{id}_sheet.png` という名前で保存する（idは各見出しの `/` のあとの英字）。
- ★**敵は背景を「透明」ではなく `#FF00FF` のマゼンタ一色で頼む**。
  敵は炎・煙・光の技を持つものが多く、透明（＝グレーの市松）だと色つきの光の中に模様が残るため
  （味方で実際に何度も起きた。PROMPTS-pose.md の 2026-07-28 追記）。
  マゼンタなら build-sprites.py の単色背景ぬきが確実に抜く。
- ★**敵も味方と同じ「右向き」で描く**。ゲームが表示のときに自動で左右反転する
  （index.html の `.unit.enemy .sprite { transform: scaleX(-1) }`）。
  ここを「敵だから左向き」と書くと、反転されて逆になる。
- ④やられ も味方と同じ描きかたでよい（頭が右がわ）。反転して左右そろう。

■ 絵にするときの約束（ユーザーと決めたこと。くずさない）
────────────────────────────────────────────────────────
- ★**実在の人物は悪者顔にしない**。角・牙・緑の肌・つり上がった悪人眉を使わない。
  堂々とした「相手役」として描く（蘇我入鹿・平知盛・今川義元・明智光秀・石田三成・
  フビライ・ハン・物部守屋・榎本武揚）。CLAUDE.md §5「失敗を責めない」のトーンに合わせる。
- 怪物にしてよいのは**架空の災いだけ**（天然痘の鬼・酒呑童子・炎鬼・火事鬼・なぞの霧・
  藩閥のぬし・物の怪）。ここで思いきり怖くすると、実在の人物の「堂々とした感じ」が引き立つ。
- ★**国や民族をまるごと悪者にしない**。黒船の面の敵は「大砲」と「弾」であって人ではない
  （ペリーは味方カードなので、なおさら）。
- ざこは名前が出ないので、**シルエットだけでどの時代か分かる**こと。
- ボスは旗・紋・かぶりもので見分ける（桔梗紋・大一大万大吉・二引両・平氏の赤旗）。

────────────────────────────────────────────────────────
■ コード側の配線（2026-08-07に**ぜんぶ入れた**。29体とも画面に出ている）
────────────────────────────────────────────────────────
1. ✅ 出し先: build-sprites.py の **ENEMY_IDS** に id を書くと `images/enemies/{id}/` へ出る。
2. ✅ ゲーム側: chars-data.js の boss/minion に **`img: "mitsuhide"`** と1行足すだけで絵になる。
   書かなければ 今までどおり絵文字。絵が読めなかったときも絵文字のまま（設計合意7の流儀）。
3. ✅ ボスの大きさ: `.unit.boss.has-sprite .sprite img` を 177.5%（＝142×1.25）にしてある。
   ★build-sprites.py は29体の背たけを ぜんぶ そろえてしまうので、
     「大将らしい大きさ」は **CSSでしか作れない**。プロンプトに「大きく」と書いても効かない。
4. ✅ 城・町（ebase）は **2026-08-08に PROMPTS-base.md へ移した**（12枚ぶんのプロンプトと
   配線・書き出しの道具 build-bases.py がある）。**4コマ不要＝1枚でよい**のは そのまま。
   みかたの城7枚・つくるもの5枚・ちからのアイコン8枚も あちらにまとめてある。

────────────────────────────────────────────────────────
■ ★29枚を実際に通して分かったこと（次に敵を足すときに読む）
────────────────────────────────────────────────────────
- **生成AIは「マゼンタ一色」と頼んでも、コマごとにマゼンタの四角を描き、
  そのあいだと まわりに 白い紙のすきまを残してくる**。四隅が白くなるので、
  四隅の色を見る従来の単色ぬきでは **白のほうを背景と判定して失敗する**。
  → build-sprites.py に **key_magenta()** を足した（マゼンタを最優先で見る）。
  ★白い紙は「**白だけをたどって画面のふちから届く所**」だけ消すこと。
    マゼンタを通して消すと、コマの中の **白い矢・白い旗・白い光まで消える**。
  ★白は2〜3px ふとらせて消すこと（WHITE_GROW）。境目に半とうめいが残ると、
    人物のまわりに **うすい四角いわく** が出る（物部守屋・今川義元で実際に出た）。
- **こうげきのコマだけ向きが外れる敵が多い**（物部守屋・フビライ・足軽・今川義元・藩閥のぬし）。
  射た矢・突き出した槍・黒い判子が右がわに大きく描かれ、暗い色の重心が右に寄るため。
  ログが「atk:左→反転」なら FACE_FIX に **"keep"** と書く（PROMPTS-pose.md と同じ流儀）。
- **合体（CELL_PICK の丸かっこ）は大きいほうを先に書く**。切り出す上下の範囲は
  最初に書いたコマの段から決まるので、けむりを先に書くと **けむりだけのコマ**になる
  （黒船のやられで実際に起きた。いまは段も合体するよう直したが、大きいほうを先に書くのが安全）。
- **背たけより高い持ち物（槍・弓・旗さしもの・碇）があると、本体が小さく描き出される**。
  足軽がいちばんひどく、味方の3分の2の大きさだった。**SIZE_ADJUST** で戻す
  （足軽1.45／今川義元1.18／物部守屋1.15／石田三成1.15 など）。
  ★自動補正の上限(ADJ_LIMIT=1.25)では足りないので、2026-08-07に
    「暴走よけは自動ぶんだけ・手書きの SIZE_ADJUST はそのままかける」に式を変えた。
- 船・火の玉・波のような**人でないもの**は **NON_HUMAN** に書く。
  「頭のはば」で大きさをそろえる補正が、顔の無い絵では でたらめな倍率になるため。
- **やられ(down)のコマは、地面に落ちた持ち物が別のコマに数えられることがある**
  （足軽の槍）。そのときは **DROP_SEED** にその点(x,y)を書いて消す。
