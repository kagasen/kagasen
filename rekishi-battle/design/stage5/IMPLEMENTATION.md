# ステージ5「名将への挑戦」実装メモ

2026-10-22。実装・ブラウザ検証済み。先生の依頼によるGitHub main反映対象版。配信完了はGitHub Pagesで確認する。

## 遊び方

- 「4」の最後をクリアすると「5」が開く。既存68面に10試練を追加し、合計78面。
- 対戦順は、石田三成 → 坂本龍馬 → 毛利元就 → 北条政子 → 伊達政宗 → 土方歳三 → 武田信玄 → 上杉謙信 → 真田信繁（幸村） → 宮本武蔵。
- 武蔵は、ほか9人すべての試練をクリアすると開く。
- 敵の城を抜けて勝つ形式ではなく、名将本人を倒すと勝利。試練のボスは復活しない。武蔵は援軍なしの単独戦。
- 初勝利でその人物が確実にLv40（スーパーレア）で加入する。再戦に勝つと＋5、Lv50まで育つ。Lv50以降の再戦でもレベルや既存の記録は下がらない。
- 勝利した時点で加入・クリアを保存する。クイズに進む前に閉じても加入は残る。
- 勝利画面から次の試練の編成へ進める。新しく加わった人物は編成欄の先頭に表示する。
- 各試練に史実に基づく3択クイズ3問を用意。クイズ後の通常カード抽選は従来の42人のまま。名将は抽選やスターターには混ぜない。

## Lv50でのおためし

- URLの末尾に `?trial=stage5` を付けると、基本42人がLv50で10試練を自由に選べる。
- 通常と同じ戦闘。初期編成は7人で、自由に組み直せる。名将は試遊中に勝つと加入する。
- 個人のセーブを読み込まず、書き込まない。勝利・加入・設定も、そのタブのメモリー内だけ。再読み込みで試遊は初期状態へ戻る。
- 上部に試遊中の表示と「いつものゲームへ」を常時表示し、戻れば以前のレベル・記録が使える。試遊中はバックアップ操作を隠す。
- 試遊は `tests/stage5-trial.mjs` で検証。低レベルの元データとバックアップの不変、新規ユーザーの記録が作られないことも確認した。

## 試練ごとの道具制限

先生の追加指示により、試練ごとに使えない城のちからを1種類ずつ設定した。史実上の禁止ではなく、ゲーム用のルール。

| 石田三成 | かみなり |
| 坂本龍馬 | さく |
| 毛利元就 | ゆみ |
| 北条政子 | 年貢 |
| 伊達政宗 | かみかぜ |
| 土方歳三 | てつはう |
| 武田信玄 | 火ぜめ |
| 上杉謙信 | あめ |
| 真田信繁（幸村） | はた |
| 宮本武蔵 | 兵糧攻め |

- ステージ一覧・編成画面・戦闘画面に制限を表示。編成時には代わりの作戦のヒントも出す。
- 禁止ボタンは斜線背景・「つかえない」の表示で無効化。待ち時間や資金が増えても有効にならない。
- 選択・照準・各発動関数でも共通の `powerAllowed()` を使い、禁止中は資金・CD・効果・照準を変えない。通常68面と味方の自動技・必殺技には制限を加えない。
- おためしモードにも同じ制限を適用。制限を外して攻略検証することはしていない。
- 設定は `chars-data.js` 末尾の `rules` 表が唯一の定義元。`blockedPowers` と `powerTip` をステージへ渡す。

## 戦闘

- 通常8秒 → 予告2.5秒 → 得意技5秒 → 隙4.5秒 → 通常7秒、を繰り返す。武蔵の二連撃だけ得意技1.1秒。
- 技の予告・発動・隙は、戦闘上部の帯の文言と色で知らせる。政宗・信繁の突撃予告には地面の印も出す。
- 先生の追加指示「レベル50もしっかりと考えてやらなければクリアできない」に合わせて再調整した。
- 隙以外はボスが攻撃を受け流し、ダメージを8％に軽減する。隙には1.8倍のダメージが通る（通常時の22.5倍）。無敵にはしない。受け流された一撃には専用の表示を出す。
- ボスが得意技を使う2回目から、敵軍全体の攻撃が12％ずつ強まり、最大2倍になる。ボスの範囲攻撃・二連撃にも適用。帯で現在の倍率を常時知らせ、再戦では1倍へ戻す。時間切れによる強制敗北はない。
- 相手を倒すまで、隙への一撃・前線の支援・回復と無敵をどう使うか選べる。編成画面で受け流し・隙・敵の強まりを事前に説明する。
- 星のめあては「勝つ」「3人以上出して勝つ」「隙に必殺技を合わせて勝つ」。1〜4の必殺技1回までの条件は変えていない。
- 時代をこえた試練として全員に1.5倍のボーナス。開始資金600、収入14/秒。
- 狭い盤では後衛を出す前に連撃が届くため、ボスの攻撃だけを準備距離に合わせて補正する。倍率は `pow(clamp((盤の幅−左右の余白)/910, 0.25, 1), 0.4)`。HP・技の周期・加入条件は同じ。1〜4の戦闘には適用しない。
- 数値は初期調整値。先生と子どもの実機での手ごたえに合わせて再調整する。

| 人物 | 敵の固有技 | 仲間の自動技（16秒ごと） |
| --- | --- | --- |
| 三成 | 兵を強化する采配 | 近くの仲間の攻撃を6秒1.2倍 |
| 龍馬 | 2回に分かれて援軍を呼ぶ | 仲間の移動を6秒1.35倍、出撃待ちを2秒短縮 |
| 元就 | 兵3体の結束で守りを強化 | 近くの仲間のダメージを6秒25％軽減 |
| 政子 | 敵の立て直しと防御支援 | 通常の回復に加え、仲間と城のダメージを6秒25％軽減 |
| 政宗 | 予告から前へ踏み込み範囲攻撃 | 踏み込み＋近くの敵に攻撃4倍のダメージ |
| 歳三 | 短い間隔で連撃 | 近くの敵へ攻撃2倍を2回 |
| 信玄 | 風・林・火・山の4種類の構え | 近くの仲間のダメージを6秒35％軽減 |
| 謙信 | 攻撃と迎撃の強化 | 自分の攻撃を6秒1.5倍、防御も強化 |
| 信繁 | 守りの構えから突撃に切り替え | 自分の防御＋近くの敵に攻撃3.5倍のダメージ |
| 武蔵 | 受け流しの構えから二連撃 | 近くの最も硬い敵へ攻撃2.5倍を2回 |

これらの効果はゲーム用の創作。人物の紹介と学習クイズには史実だけを用いている。モチーフの出典と伝承については [デザイン案](README.md) を参照。

## 保存と互換性

- `rekishiBattle.save.v1` を継続使用。追加人物は従来の `cards`、試練は `cleared`・`chal` に新しいidを追加する。
- 旧42人・68面のデータ、金色の仲間、MVP、勝利数、クイズ履歴、バックアップに入る記録を維持する。
- エンディングと全員MAXのごほうびは、従来の1〜3・42人のまま。名将の獲得やステージ5の星を新条件にしていない。
- `CHARS` は基本42人、`LEGENDS` は追加10人、`ALL_CHARS` は編成・カード表示用。基本の年表やクイズの年代順を崩さない。
- `seriesHigh()` は3・4の従来演出用。5のボス技・加入は `isLegendStage()` と `B.trial` で扱う。
- 効果の秒数は戦闘の `tick` で数える。再戦ごとに状態を作り直し、ステージ定義に倍率を重ねない。

## 検証

- 道具制限の専用ブラウザテストで、全10面の表示・無効ボタン・発動防止・資金不変、旧68面で制限がないこと、旧面で全10道具が使えること、4画面幅を確認。

```sh
python3 -m http.server 8879 --bind 127.0.0.1
node --test rekishi-battle/tests/stage5-data.test.mjs
node rekishi-battle/tests/stage5-browser.mjs
node rekishi-battle/tests/stage5-trial.mjs
node rekishi-battle/tests/stage5-power-rules.mjs
node rekishi-battle/tests/stage5-balance.mjs 768

```

ブラウザ用テストはPlaywrightとChromeを使用。`BASE_URL`、`PLAYWRIGHT_MODULE`、`CHROME_PATH`で環境を指定できる。ユーザーのブラウザとは別の保存領域で実行する。

- データテスト4件すべて成功。42人・68面が追加前と一致することもブラウザテストで確認。
- 実際のボタンで、試練開始→出撃→撃破→加入→次の編成→新人物の出撃→3問クイズ→カード獲得を通過。
- 全10人の予告・技・隙、初回加入、Lv45/50への再戦育成、同じ勝利の二重報酬防止、敗北時の報酬なし、全員の固有技、効果の期限、隙に使う必殺技の星を確認。
- 1180×820、768×1024、390×844、320×740で編成・戦闘・勝利・図鑑を確認。320pxでの7人欄のはみ出しを修正。
- 一度読み込んだ40枚の画像を使い、通信を切った再読み込み・武蔵戦の起動と保存復元を確認。画像404・JSエラー0。
- Lv50の従来42人のみを使い、1180・768・390pxで3編成・7戦法を比較。各画面幅で道具制限を適用した10試練すべてに「編成・隙・使用できる支援を使う」攻略例を確認した（最短56〜149秒）。一方、同じLv50の基本2編成でも「出撃＋満タンですぐ必殺」だけでは60戦すべて敗北。「必殺なし＋通常支援」も30戦すべて敗北した。
- 「即撃ちでも通常支援を使う」比較では一部に勝利例が残る。隙以外を完全無効にせず、別の作戦で補える余地は残している。攻撃型・回復重視のどちらか一方ですべて勝てるようにはしていない。これらは用意した自動プレイの検証結果であり、すべての編成・戦法についての証明ではない。
- 数値と全戦の記録は [validation-summary.json](validation-summary.json)。テストは実際の戦闘処理を使い、資金・レベル・敵の数値を戦闘中に書き換えない。画像演出のみ省略する。
- `build-seo.mjs --check` は差分なし。
- 共通release-checkは歴史バトルのエラー0。全体では、作業開始前から変更のあった別アプリ `goisen` のSW版据え置きエラー1件と、既存警告5件が残る。
- iPad/iPhone実機・Safariでの手触りは未確認。難易度の最終判断は実機で行う。
