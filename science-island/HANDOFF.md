## クリアの まどは すぐ 出す。かわりに「見なおす」出口を つける（2026-09-10 ユーザー指てき）

もとの 指てきは 「まだ 頭の せいりが できて いないのに クリアが 出るので『もぉー』となる」。
そこで **いちど「できた！」の おびで クリアを 止める** 形に した が、実きで ためして もらって
**「完成した ときの うれしさが 半減する」**と 分かった ので、いまの 形に した。

**せいかい → 480ms → クリアの まど（コンフェッティも すぐ）**。
まどの 中に 3つめの ボタン **「🔍 じぶんの こたえを 見なおす」**（`#modal-look`）を おき、
おすと まどが どいて **見なおしの おび**（`#clear-bar`）に かわる。
ばんめん（作った 回路・つり合い・ならべた じゅんばん）は そのまま のこって いる。
おびからは 「◀ けっかに もどる」（`#cb-back`）と 「▶ つぎへ すすむ」（`#cb-next`）。

- **13の 型 ぜんぶが 通る `tryClear()` 1か所**なので、どの ゲームでも 同じ ながれ
- `onClear()`＝記ろく＋中みづくり＋コンフェッティ、`openClearModal()`＝まどを 出すだけ。
  **見なおしから もどる ときは `openClearModal()` だけ を よぶ**ので、
  セーブも コンフェッティも やりなおさない
- 「つぎへ」は まどにも おびにも あり、どちらも `goNextStage()` を よぶ（しょりを 2か所に 書かない）
- `loadStage()` と `go()` で おびを かたづける
- `MUST_WIRE` に `#modal-look` `#cb-back` `#cb-next` を 足した ので、
  どれかが 死んだら ビルドが 止まる

## エンジンを ふやす／直す ときの きまり

**その 型の コードは ぜんぶ `engines/○○.js` の 中に 置く。とうろく行も その ファイルに 書く。**

これを やぶると **その 型を つかわない 島だけ 遊べなく なる**。分割した ときに
じっさいに 4つ 出た（もとの 1ファイルでは どれも 無害だった）:

| 見つかった もの | どこに あった | どこへ うつした |
|---|---|---|
| `attrUp()` | `engines/tsunagu.js`（⚡専用） | `20-shell.js`（共通）。ホームの 島タップが 全島で 死んで いた |
| `craneArt()` | `engines/suiri.js`（🧪専用） | `engines/factory.js`（つかう 側） |
| `swingStop()` の 直よび | `92-boot.js` が じかに よんで いた | `ENGINES.swing.stop` に して、がめんを 出る ときに 全エンジンの stop を よぶ |
| `renderMitsukeru()` / `tapMitsukeru()` / `ENGINES.mitsukeru` | `engines/sodate.js` の 中 | `engines/mitsukeru.js` |

`hintAnswer` も 型の 名まえを ならべる のを やめて `ENGINES[kind].hintAnswer` に した。

## 0. このアプリの狙い（ぶらさないこと）

| てこのつり合い | 6年 | 中1 力 → 高校物理のモーメント（式がそのまま生き残る） |

**回路の判定は「本当に解いている」** — ここがこのアプリの心臓部なので消さないこと。

1. 導線と入っているスイッチで端子を Union-Find でくっつけて「節点」にする
2. でんちの ＋と− が同じ節点なら **ショート**
3. そうでなければ **節点解析（MNA）＋ガウス消去** で連立方程式を解いて各でんきゅうの電流を出す

正解の配線を人が用意していないので、**別解も自動で正解になる**（＋−を逆にしてもOK、スイッチを電池の手前に
入れてもOK）。明るさも計算値そのまま（1こ=1.5A→`full` ／ 直列2こ=0.75A→`dim` ／ 並列2こ=各1.5A→`full`）なので、
「直列はくらい・並列は明るい」が画面で見て分かる。しきい値は `evalCircuit` の `ratio < 0.06 / < 0.78`。

  6もん目で2こともスイッチの先／6もん目を直列にする、など8パターン）
- 別解が通る（＋−逆・スイッチの位置ちがい）

#### じっけん型は「くみ立てるだけ」では 面白くなかった（2026-08-24 やりなおし）

はじめは じょうけんを えらぶ 表だけで、**じっけんが 走らなかった**。
ふりこの いちばん 面白い ところ（ならべて ふらせると 長い ほうが 目に見えて おそい）が
まるごと 抜けて いて、答えは learn の 文で 教えて いた。作りなおした。

いまの ながれ: **①くみたて＋よそう → ②じっけん（アニメ）→ ③けっか**

- `SIMS` に じっけんの なかみを とうろくする（`st.sim` で えらぶ）。`SIMS.furiko` は
  **T = 2π√(L/g)** の ほんものの 式。25cm→1.00びょう、100cm→2.01びょう。
  おもさ・ふれはばでは かわらない ―― これを **文で 教えず、目で 見せる**
- **よそう**（A/B/同じ）を 先に えらばせる。あたっても 外れても せめない。
  外れたら「✨ よそうと ちがった！ それが 発見だよ」
- **じょうけんを そろえずに 走らせる ことも できる**。その ときは 時間の ちがいを 見せた うえで
  「A と B は ちがう ところが 2つ いじょう ある。これでは どちらが きいたのか 分からないね」。
  ここが この型で いちばん 効く ところなので **消さない**
- クリアは `cur.phase === 'done' && jikkenFair()`。**走らせて けっかを 見るまで クリアに ならない**
- アニメは 4ばい はやおくり（100cmの 10おうふく＝20びょう → 5びょう）。まちきれない ときは
  ばんを タップ すると けっかへ とぶ
- かるくする ため、毎フレーム さわるのは 糸と おもりの `<g>` の `rotate` と 数字だけ
  （えは かきなおさない）。だから 糸と おもりは **まっすぐ 下**に かいて ふれは rotate で 出す

あたらしい じっけんを 足すときは `SIMS` に `{laps, vals, period, art}` を 1つ 足す。
`st.sim` を 書かなければ くみ立てだけ（アニメなし）でも 動く。

#### 作りながら 直したこと

- **むすぶ型のせん**は 地球を よけて そとがわに ふくらませる（`mbWireD`）。まっすぐ 引くと 地球に かさなって 「地球に つないだ」ように 見える

## 2026-08-27 — verify の まぐれ ❌ を なくした（たね固定＋しっぽの 見かたを 直した）

でんじしゃくバトルの 章が 5回に1回くらい ❌ に なって いた 件。**アプリの 不具合では なく

直した ところは 3つ:

1. **乱数を たねから 作る**（`verify.mjs` の あたま）。xorshift32 を Node標準だけで 書いて
   `Math.random` を まるごと 差しかえた。たねは `20260827` 固定。`index.html` から とり出した
   コードも グローバルの `Math.random` を つかうので まとめて 決定ろん的に なる。
   → **何度 走らせても 出力が 1バイトも かわらない**。❌ が 出たら かならず 本もの。
   たねを かえて ためしたい ときは `node science-island/verify.mjs --seed 12345`。
   くみあわせ ごとに `reseed()` で たねを もどして いる ので、**よその 章を 直しても
   でんじしゃくの 数は うごかない**（前の 章が 乱数を 何回 つかったかに 左右されない）。
2. **局数を 8 → 60局に ふやした**（さいしょの 事こは 40局）。8局だと へいきんが
   **17手〜55手**も ぶれて いた。60局なら **28手〜41手**に おちつく（たね20とおりで 実そく）。

   **つぎに まぐれで 落ちる のは ここだった**。いまは 3.0〜3.7。
3. **「さいあく（最大）」で 判定するのを やめた**。最大は 局数を ふやすほど 大きく なるし、
   まれな 1局に ぜんぶ 引っぱられる ので、たねを かえると **91手〜223手**も ぶれる
