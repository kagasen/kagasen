# 🌐 オンライン対戦の サーバーを 用意する（先生むけ手順書）

「せかいをまわろう！」の **ともだちと あそぶ（オンライン対戦）** をつかうには、
インターネット上に「へやサーバー」を1つ置く必要があります。ここではその手順を書きます。

- かかるお金: **0円**（Cloudflare の無料プランの範囲。下の「お金の話」を読んでください）
- かかる時間: だいたい **15分**
- 1回やれば、あとは何もしなくて大丈夫です（アプリを更新してもサーバーは触りません）

> **なぜ先生の作業なのか**: アカウント作成とログインはパスワードを扱うので、AIが代わりにできません。
> コードは全部用意してあります。コピペで進められます。

---

## このサーバーがやること・やらないこと

| やること | やらないこと |
|---|---|
| へやを作る／あいことばで入れる | ゲームのルール（山札・勝ち負け）※これは**ホストの端末**が持ちます |
| メッセージをそのまま転送する | 記録を保存する（データベースは使いません） |
| だれか切れたら知らせる | 名簿・学習記録を受け取る（**そもそも送っていません**） |

サーバーを通るのは「あいことば・えらんだ動物の名前・出したカード」だけです。
へやは全員が出たら消えます。**子どもの記録は端末のなかだけ**、という約束はそのままです。

---

## 手順

### ① Cloudflare のアカウントを作る（まだ持っていなければ）

<https://dash.cloudflare.com/sign-up> でメールアドレスとパスワードを登録します。
クレジットカードの登録は **要りません**（無料プランのままで動きます）。

### ② パソコンでこのフォルダを開く

ターミナル（Mac なら「ターミナル」アプリ）で:

```
cd ~/kagasen_projects/kagasenapplication/sekai-o-mawarou/server
```

※ フォルダを別の場所に置いている場合は、その場所に合わせて読みかえてください。

### ③ ログインする

```
npx wrangler login
```

ブラウザが開いて「許可しますか？」と聞かれるので **Allow** を押します。
（`npx` は最初だけダウンロードで少し時間がかかります）

### ④ 名前を決める（そのままでもOK）

`wrangler.toml` の1行目、`name = "sekai-o-mawarou"` がサーバーの名前になります。
このままだと URL が `https://sekai-o-mawarou.<あなたのID>.workers.dev` になります。
変えたいときだけ書きかえてください（英数字と `-` だけ）。

### ⑤ 出す（デプロイ）

```
npx wrangler deploy
```

最後に、こんな行が出ます:

```
Deployed sekai-o-mawarou triggers (0.34 sec)
  https://sekai-o-mawarou.あなたのID.workers.dev
```

**この URL をコピーしてください。** これが「へやサーバー」の住所です。

### ⑥ アプリに URL を教える

`sekai-o-mawarou/index.html` を開いて、`NET_SERVER_URL` の行を探します
（「★★ここだけ 書きかえる★★」と書いてあります）。

そこに、⑤の URL を **`https://` → `wss://` に変えて、うしろに `/ws` をつけて** 貼ります:

```js
var NET_SERVER_URL = 'wss://sekai-o-mawarou.あなたのID.workers.dev/ws';
```

あわせて `sekai-o-mawarou/sw.js` の `CACHE` の番号を1つ上げます（v5 → v6 のように）。
これをしないと、前に開いた端末で古いページが表示されたままになります。

### ⑦ 動くか確かめる

1. GitHub Pages に push して、実際のアドレスでアプリを開く
2. 「🌐 ともだちと あそぶ」→ 名前を選ぶ →「へやを つくる」
3. **あいことば（4文字）** が出たら成功です
4. べつの端末（もう1台のiPadやスマホ）で同じページを開いて、そのあいことばで「はいる」
5. ホスト側で「みんなで 出発！」

うまくいかないときは、下の「困ったとき」を見てください。

## お金の話（無料でおさまります）

Cloudflare の無料プランには **1日 10万リクエスト** の枠があります。
このゲームの1試合はだいたい **20リクエスト**なので、計算上 **1日5,000試合**まで無料です。
（WebSocket は「受信20通で1リクエスト」の計算、待っているあいだは Hibernation で課金されません）

1クラス40人が毎日遊んでも、枠の1%も使いません。
使用量は Cloudflare のダッシュボード → Workers & Pages → sekai-o-mawarou で見られます。

## 困ったとき

**`Error: You need to register a workers.dev subdomain`**
→ ダッシュボードで一度 Workers を開き、サブドメイン（あなたのID）を決めてから、もう一度 `npx wrangler deploy`。

**`Durable Objects requires a paid plan` のようなエラー**
→ `wrangler.toml` の `new_sqlite_classes` が `new_classes` になっていないか確認してください。
無料プランでは **SQLite版（new_sqlite_classes）** である必要があります。

**アプリで「サーバーに つなげなかったよ」と出る**
→ `NET_SERVER_URL` が `wss://` で始まり、うしろに `/ws` が付いているか確認。
→ ブラウザで `https://〇〇.workers.dev/health` を開いて `ok` と出るか確認。

**学校のネットワークでつながらない**
→ WebSocket が塞がれている可能性があります。校内Wi-Fiではなく、
　 ためしに別の回線（テザリング等）で試すと切り分けられます。

**やめたくなったら**
```
npx wrangler delete
```
でサーバーごと消せます。アプリ側は `NET_SERVER_URL = '';` に戻せば
「オンライン対戦は まだ つかえないよ」と出るだけで、1人あそびは今までどおり動きます。

## 開発する人へ

手もとで動かして試すとき（デプロイなしで確認できます）:

```
cd sekai-o-mawarou/server
npx wrangler dev --port 8787 --local
```

アプリを `http://localhost:8766/sekai-o-mawarou/index.html` のように **localhost** で開くと、
自動で `ws://localhost:8787/ws` につなぎます（`NET_SERVER_URL` は見ません）。

もっと軽く試したいときは、node だけで動く同じプロトコルの偽サーバーもあります:

```
node sekai-o-mawarou/net-server.mjs
```

プロトコルの詳細と、ホスト権威のしくみは `../HANDOFF.md` の「🌐 オンライン対戦」を読んでください。
