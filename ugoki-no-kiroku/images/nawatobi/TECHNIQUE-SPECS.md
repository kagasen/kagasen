# なわとび画像生成・検査仕様（n1〜n19）

この文書は、画像生成担当と検査担当が同じ動作定義を共有するための基準である。技名・並び順は `ugoki-no-kiroku/index.html` の `NAWATOBI_SKILLS` に合わせる。

## 全画像共通

- 横長3コマを基本とし、左から右へ時間が進む。2コマ指定の技でも、必要なら3コマ目を「着地／次周期直前」に使う。
- 同一の小学生女子を全コマで使う。濃茶のポニーテール、青い半袖シャツ、オレンジの短パン、白い靴下、青白の運動靴。顔・髪・服・身長比を途中で変えない。
- 既存鉄棒画像と同じ、立体感のある児童向けアニメ調。白〜ごく薄い水色の無地背景、柔らかい影、明瞭な輪郭、オレンジの動作矢印。
- 縄はオレンジ、持ち手は青。縄の両端は各コマで必ず左右の持ち手外端へ接続する。縄が身体、手、靴を不自然に貫通してはならない。
- 前回しは「背中側から頭上を越え、顔の前へ下り、足下を前から後ろへ抜ける」。後ろ回しはその完全な逆で「顔の前から頭上を越え、背中側へ下り、足下を後ろから前へ抜ける」。側面または斜め前から描き、矢印だけでなく縄の位置でも方向を区別する。
- 1回旋技は、同じ縄が頭上・前後・足下へ移る位相を描く。二重・三重は「1回の高い跳躍中」に2回／3回通過する。人物ごとに別々の上向き矢印を置いて複数回跳んだように見せない。
- 人体検査: 腕2本、脚2本、靴2足、左右の手に持ち手1本ずつ。余分な指・手足、融合、逆関節、左右反転、靴底の不自然な向き、縄と指の融合を不合格とする。
- 基本姿勢は、目線を前、上体をほぼ直立、肘を体側近く、手首で小さく回す。通常跳躍は低く両足のつま先寄りで着地。二重・三重だけ少し高く跳ぶ。
- 縮小カードで技の差が残るよう、足形・腕の交差・縄の方向・`×2`/`×3` を大きく単純に描く。長文は画像内に入れず、丸数字や短い記号に限る。
- 全技共通の絶対NG: 写真調、別人化、男子化、背景小物、文字化け、コマごとの視点反転、縄の断線、左右ハンドルの欠落、余分な縄、人物と縄の前後関係の破綻。

## 混同防止の最終照合

| 組み合わせ | 正しい差 |
|---|---|
| あやとび / こうさとび | あやは周期ごとに `開く⇄交差`。こうさは全周期で交差を保持。 |
| はやぶさ / こうさにじゅう | はやぶさは同じ1跳躍の1回目が開き、2回目が交差。交差二重は1回目も2回目も交差。 |
| 前系 / 後ろ系 | 前は縄が顔の前へ下りる。後ろは縄が背中側へ下りる。人物の向きを反転して済ませず、縄の矢印と足下への進入側を逆にする。 |
| 1回旋2跳躍 / 二重跳び | 前者は縄1回転にジャンプ2回。後者はジャンプ1回に縄2回転。上向き矢印の数と `×2` の対象を逆にしない。 |
| 二重 / 三重 | どちらも1跳躍。足下通過数だけが2回／3回で、三重はより高い跳躍と `×3`。 |
