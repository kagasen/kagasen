# 鉄棒20技 画像制作仕様

## 共通ルール

- 基準画風は `t1-tsubame.png`。同じ児童、服装、青い低鉄棒、立体的な2.5D教材イラストに統一する。
- 原則は横から少し正面が見える3/4側面。手の握り、鉄棒との接触部、左右の脚が判別できる角度を優先する。
- 回転技は、支点と回転方向が最も分かる途中姿勢＋オレンジ矢印。必要なら小さな開始姿勢を添える。
- 手指、親指、肘、膝、足首、鉄棒の前後関係を必ず検査する。鉄棒の二重化・途切れ・人体貫通は不採用。
- 背景は無地の白。文字・技名は画像に入れない。

## 技別の姿勢基準

| ID | 技 | 画像で固定する動作 |
|---|---|---|
| t1 | つばめ | 順手の支持。肘を伸ばし、腕で鉄棒を押す。下腹部を棒に当て、頭から足先まで一直線。 |
| t2 | ふとんほし | おへその下を棒に掛け、体を「く」の字にして脱力。頭・腕と脚が棒の両側へ垂れる。 |
| t3 | まえまわりおり | 支持から腹で棒を挟み、マットを見て上体を前へ。膝を曲げて小さく回り、両手は握ったまま。 |
| t4 | あしぬきまわり | 両手で懸垂し、膝を胸へ引き付けて両脚を両腕の間へ通す。肩を後方へ倒し、体を小さくして後方回転。 |
| t5 | こうもり | 両膝裏を棒に掛けた逆さ懸垂。左右の膝を確実に掛け、手を離して頭と腕を下へ。 |
| t6 | こうもりおり | 両膝掛けから両手をマットへ着く。両膝裏が棒に接触し、頭は鉄棒の奥側、顔と両手は正面側を向く。足・顔・手の向きを矛盾させない。 |
| t7 | ちきゅうまわり | 棒の下で逆さになり、左右の手を入れ替えて両腕をX字に交差したまま握る。両脚は左右へ大きく開き、両膝を曲げて足先を棒の左右へ分ける。正面から交差と開脚が同時に見える姿勢。 |
| t8 | ふみこしおり | 支持から片脚を棒の上へ乗せ、足裏で棒を踏み、もう一方の脚を棒の向こうへ越して安全に下りる途中。 |
| t9 | あしかけあがり | 左膝裏の深いくぼみに棒を掛け、左ももと左ふくらはぎで棒を挟む。右脚を大きく振り、肘を曲げて前後開脚支持へ上がる。棒を股・尻・太ももへ置かない。 |
| t10 | あしかけぜんてん | 横向きで片膝裏を棒に深く掛け、その膝裏を支点にする。両手で棒を握り、背中を丸め、あごを引き、頭と肩から棒の前下方へ回る。反対の自由脚は後上方へ長く伸ばす。 |
| t11 | あしかけこうてん | 片膝裏を棒に掛けて両手で握り、反対脚を振って後方回転する。開始姿勢では上体を起こし、反対脚を下へ伸ばす。後方へ倒れる矢印は上から下向きにする。 |
| t12 | さかあがり | 順手で肘を曲げ胸を棒へ引き付け、踏切脚で蹴り、振上げ脚を後上方へ。実体の脚は必ず2本。動きを補う場合だけ1本分の薄く透けた残像を使う。 |
| t13 | だるままわり | 下腹部と両太ももで棒を挟み、膝を胸へ抱えて小さな球になる。両手は膝の左右で棒を握る。両足・脛・太ももは棒より手前に置き、身体中央の棒は隠す。 |
| t14 | プロペラまわり | 頭を棒より下、伸ばした両脚を揃えて真上に置く逆さの垂直姿勢。股・腰付近を支点に、両手で棒を握って横方向へ回る。 |
| t15 | こうほうしじかいてん | 支持から下腹部・腰を棒につけたまま、膝を曲げて肩と頭を後ろへ倒し、後方へ支持回転する。 |
| t16 | ひこうきとび | 棒の上へ両足を左右に開いて乗せ、その両足の間で両手が棒を握る。棒上の並びは「左足―左手―右手―右足」。握ったまま身体と両脚が棒の下をくぐって前方へ抜ける軌道をオレンジ矢印で示す。 |
| t17 | じごくまわり | 両膝裏を棒に掛け、両手で棒を握ったまま、膝裏を支点に後方へ回転。頭を入れ、膝掛けを外さない。 |
| t18 | てんごくまわり | 棒上で両手を体の横に置き、膝を胸へ引き付けて小さく丸まる。腹部付近を棒に保ちながら前方へ回転する軌道を示す。 |
| t19 | ぜんぽうしじかいてん | 支持から上体を前へ倒し、股・下腹部の折れ目を棒に密着させたまま、膝を曲げて前方支持回転。中央の棒は身体に隠し、両手は握り続ける。 |
| t20 | けんすいさかあがり | 足が地面から離れた懸垂から、肘を曲げ胸を棒へ引き付け、膝を胸へ、脚を棒の上へ運んで後方回転する途中。3段階の右端は、左右の手で棒を握り、顔を見せず後頭部を下へ、両足を右上へ向ける。 |
