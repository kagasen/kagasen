## 7. 撮影・編集メモ

- **画面収録は先に全部撮る**。声は後乗せ（アフレコ）にすると、打ち間違いを気にせず打てる。
- 実際に打つ手元は映さなくてよい。**画面内のキーボード＋手のイラストが手元カメラの代わり**になるのが、このアプリの強み。むしろそこを大きくズームする。
- タイプ音・正解音・ミス音は残す。**ミスの「ブッ」という音と画面の揺れは必ず1回見せる**（説明より伝わる）。
- 画面収録は横向き固定。iPadで撮るなら「画面収録」で通知OFF。
- テロップは1画面3行まで。子どもも見る可能性があるので、漢字にはふりがな……は不要（視聴者は大人）だが、**アプリ内の文字はひらがな中心**であることは一度言及すると刺さる。
- 尺が10分を超えそうなら、削るのは **1:10–2:05 の「なぜ作ったか」ではなく、6:45–7:40 のショップ**（ショートに切り出せる）。
- BGMは終始1曲でよい。実演パートは音量を下げる（打鍵音を聞かせる）。

## 10. 台本に書いた事実の根拠（言い間違い防止）

| 動画で言うこと | 実装上の根拠 |
|---|---|
| 全70ステージ、レベル1は「Fを20回」 | `typing/tokkun70/level01.html`（`key:'f', total:20`）、`tokkun70/index.html` の STAGES 70件 |
| ボスはタイムアタック、最後は「あ〜ん を60秒以内」 | `tokkun70/level70.html`（【ボス】あ〜んまでタイムアタック） |
| 短文タイピングは60秒 | `typing/app.js`（`timeLeft` 初期値 60） |
| 称号23段階「はじまりの一歩」〜「神」 | `typing/app.js` RANK_LIST（23件） |
| 次に押すキーと使う指が光る | `typing/app.js` の Keyboard / HandsOverlay / FINGER_MAP |
| 短文は2〜6年で1100以上 | data.js の WORDS_HIGH：2年138／3年200／4年240／5年238／6年299＝1115 |
| 単語は1100以上（流れる単語で使用） | WORDS_LOW：140／200／240／237／299＝1116（かな12字以下を出題） |
| 流れる単語は60秒、30文字連続で+1秒／60文字で+2秒、称号36段階 | `typing/nagare3nen.html`（GAME_TIME=60, bonusSec, RANK_TABLE 36件） |
| ポイントは全モード合算 | いずれも localStorage `typing_total_points` に加算 |
| たまごの値段（100/500/1000/2500/5000/77777） | `typing/shop.html` の price |
| 育成は あたためる→エサ→あそぶ の3段階、10匹まで | `typing/shop.html`（WARM_NEEDED 80 / FEED_NEEDED 50 / PLAY_NEEDED 50 / MAX_PETS 10） |
| ガチャ要素なし | CLAUDE.md §6「ガチャ・課金的な運要素は不採用」 |
| 記録は端末内のみ、外部送信なし | localStorage のみ（CLAUDE.md §1） |
| 💾バックアップ・ひきつぎ | `typing/index.html` の BackupKit（ポイント・ペット・とっくんの3キー） |
| オフラインで動く／ホーム画面に追加できる | PWA（manifest.json / sw.js）＋フォント・Tailwind・React を同梱 |
| アプリは28個 | `apps.js` 32件のうち `draft: true` が4件 |

※ 数字を動画で言うときは「1100以上」「70ステージ」のように**丸めて**言い、細かい内訳はテロップに出さない（更新で古くなるため）。
